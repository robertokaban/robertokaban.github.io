Pendahuluan #

Setelah mengenal apa itu MySQL dan keunggulannya, langkah selanjutnya adalah menginstalnya di komputer atau server Anda. MySQL tersedia untuk berbagai sistem operasi, dan cara instalasinya pun berbeda-beda tergantung platform yang digunakan.

Artikel ini akan membahas instalasi MySQL di tiga sistem operasi utama: Windows, Linux (Ubuntu), dan macOS. Pilih bagian yang sesuai dengan sistem operasi Anda.

Instalasi MySQL di Windows #

Di Windows, metode instalasi yang paling mudah dan direkomendasikan adalah menggunakan MySQL Installer (file MSI). Installer ini tidak hanya memasang MySQL Server, tetapi juga menyediakan alat konfigurasi grafis serta komponen pendukung seperti MySQL Workbench.

Prasyarat #

  • Windows 64-bit (MySQL 8.4 hanya tersedia untuk 64-bit)
  • Microsoft Visual C++ 2019 Redistributable Package (biasanya sudah terpasang, tetapi jika belum, unduh dari situs Microsoft)

Langkah-langkah #

  1. Unduh MySQL Installer Kunjungi halaman unduhan resmi MySQL: https://dev.mysql.com/downloads/installer/. Pilih MySQL Installer for Windows (versi web atau full). Jika ingin menghemat waktu, pilih versi full yang sudah membundel semua komponen.

  2. Jalankan Installer Double-click file .msi yang telah diunduh. Pada layar pemilihan tipe setup, pilih Developer Default untuk mendapatkan MySQL Server, Workbench, dan alat pengembangan lain sekaligus.

  3. Konfigurasi Instalasi Ikuti wizard hingga halaman Installation. Klik Execute untuk memulai proses instalasi. Tunggu hingga semua komponen berstatus Complete.

  4. Konfigurasi MySQL Server Setelah instalasi selesai, MySQL Configurator akan terbuka otomatis. Pada bagian Type and Networking, biarkan konfigurasi default (Port 3306, Development Computer). Pada bagian Authentication Method, pilih Use Strong Password Encryption (disarankan untuk MySQL 8) atau Legacy jika ada aplikasi lama.

  5. Atur Password Root Masukkan password untuk user root. Catat dan ingat password ini, karena diperlukan untuk mengakses MySQL nanti.

  6. Selesaikan Konfigurasi Klik Execute pada langkah terakhir. Setelah semua centang hijau, klik Finish. MySQL Server akan berjalan sebagai Windows Service dan otomatis aktif saat komputer dinyalakan.

Menambahkan MySQL ke PATH (Opsional namun Direkomendasikan) #

Agar perintah mysql dapat dijalankan dari Command Prompt mana pun, tambahkan folder bin MySQL ke variabel PATH:

  • Cari Edit the system environment variables di Start Menu.
  • Klik Environment Variables → pilih Path → Edit → New.
  • Masukkan path seperti C:\Program Files\MySQL\MySQL Server 8.4\bin.
  • Simpan dan buka Command Prompt baru, lalu uji dengan mysql --version.

Instalasi MySQL di Linux (Ubuntu) #

Pada distribusi Ubuntu, MySQL tersedia di repositori resmi sehingga instalasi dapat dilakukan dengan cepat melalui apt.

Prasyarat #

  • Ubuntu 22.04 / 24.04 (atau versi lain yang masih didukung)
  • Akses user dengan hak sudo

Langkah-langkah #

  1. Perbarui Repositori

    sudo apt update

  2. Instal MySQL Server

    sudo apt install mysql-server -y

    Perintah ini akan memasang MySQL Server beserta dependensinya.

  3. Verifikasi Instalasi

    mysql --version

    Output contoh: mysql Ver 8.4.8-0ubuntu1 for Linux on x86_64 ((Ubuntu)).

  4. Jalankan dan Aktifkan Service

    sudo systemctl enable mysql
sudo systemctl start mysql
sudo systemctl status mysql

    Pastikan status menunjukkan active (running).

  5. Amankan Instalasi Instalasi baru MySQL di Ubuntu biasanya mengizinkan user root masuk tanpa password melalui socket. Jalankan skrip keamanan:

    sudo mysql_secure_installation

    Ikuti prompt untuk mengatur password root, menghapus user anonim, dan menghapus database test.

    Catatan untuk MySQL 8 di Ubuntu: Jika Anda ingin menggunakan autentikasi password (bukan socket) untuk user root, Anda mungkin perlu mengubah metode autentikasi. Namun untuk penggunaan lokal, metode socket sudah aman.

Instalasi MySQL di macOS #

Di macOS, cara termudah adalah menggunakan Homebrew, package manager populer untuk macOS.

Prasyarat #

  • Homebrew sudah terpasang. Jika belum, jalankan perintah instalasi dari situs resmi Homebrew.

Langkah-langkah #

  1. Perbarui Homebrew

    brew update

  2. Instal MySQL

    brew install mysql

    Homebrew akan menginstal versi stabil terbaru.

  3. Jalankan Service MySQL

    brew services start mysql

    Perintah ini akan menjalankan MySQL sebagai service latar belakang yang otomatis aktif saat login.

  4. Amankan Instalasi

    mysql_secure_installation

    Skrip ini akan memandu Anda mengatur password root, menghapus user anonim, dan melakukan pengamanan dasar lainnya. Jawab Y pada setiap prompt untuk konfigurasi yang aman.

  5. Hubungkan ke MySQL

    mysql -u root -p

    Masukkan password yang telah diatur. Jika berhasil, Anda akan melihat prompt mysql>.

Konfigurasi Awal Setelah Instalasi #

Terlepas dari sistem operasi yang digunakan, ada beberapa langkah konfigurasi awal yang sebaiknya dilakukan agar MySQL aman dan siap digunakan.

1. Menjalankan mysql_secure_installation #

Skrip ini tersedia di semua platform dan membantu mengamankan instalasi MySQL dengan cara:

  • Mengatur password untuk akun root.
  • Menghapus akun root yang dapat diakses dari luar localhost.
  • Menghapus akun user anonim.
  • Menghapus database test beserta hak aksesnya.
  • Memuat ulang tabel privilege.

2. Membuat User Khusus Aplikasi #

Sebaiknya jangan menggunakan user root untuk aplikasi sehari-hari. Buat user baru dengan hak akses terbatas:

CREATE USER 'app_user'@'localhost' IDENTIFIED BY 'PasswordKuatAnda!';
GRANT ALL PRIVILEGES ON nama_database.* TO 'app_user'@'localhost';
FLUSH PRIVILEGES;

Ganti app_user, PasswordKuatAnda!, dan nama_database sesuai kebutuhan.

3. Menguji Koneksi #

Setelah konfigurasi, uji koneksi menggunakan user baru:

mysql -u app_user -p

Jika berhasil masuk, instalasi dan konfigurasi MySQL Anda sudah selesai.

Ringkasan #

Platform Metode Perintah Kunci
Windows MySQL Installer (MSI) Jalankan installer, konfigurasi via wizard
Ubuntu APT sudo apt install mysql-server
macOS Homebrew brew install mysql

Setelah instalasi selesai, jangan lupa menjalankan mysql_secure_installation untuk mengamankan server, dan buat user khusus untuk aplikasi Anda. Pada artikel berikutnya, kita akan membahas arsitektur dan komponen internal MySQL.
