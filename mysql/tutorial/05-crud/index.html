Pendahuluan #

Setelah skema database toko_online terbentuk pada artikel sebelumnya, sekarang saatnya mengisi dan mengelola datanya. CRUD adalah akronim dari empat operasi dasar yang akan Anda lakukan hampir setiap hari:

  • Create — menambah data baru (INSERT)
  • Read — membaca data (SELECT)
  • Update — mengubah data (UPDATE)
  • Delete — menghapus data (DELETE)

Artikel ini membahas keempat operasi tersebut dengan contoh menggunakan tabel pelanggan dan produk yang sudah kita buat.

Asumsi: Anda sudah menjalankan skrip pembuatan skema pada artikel sebelumnya dan sedang berada di database toko_online (USE toko_online;).

Create: Menambah Data dengan INSERT #

Sintaks Dasar #

INSERT INTO nama_tabel (kolom1, kolom2, ...)
VALUES (nilai1, nilai2, ...);

Contoh: Menambah Satu Baris #

INSERT INTO pelanggan (nama, email, telepon)
VALUES ('Budi Santoso', 'budi@example.com', '081234567890');

Karena kolom id bertipe AUTO_INCREMENT dan dibuat_pada punya DEFAULT CURRENT_TIMESTAMP, keduanya tidak perlu diisi — MySQL akan mengisinya otomatis.

Menambah Beberapa Baris Sekaligus #

Lebih efisien daripada menjalankan INSERT berkali-kali:

INSERT INTO pelanggan (nama, email, telepon) VALUES
  ('Siti Aminah', 'siti@example.com', '081298765432'),
  ('Andi Wijaya', 'andi@example.com', '081377788899'),
  ('Dewi Lestari', 'dewi@example.com', NULL);

Menambah Data ke Semua Kolom #

Jika Anda ingin mengisi semua kolom sesuai urutan definisi tabel, nama kolom bisa dihilangkan:

INSERT INTO produk VALUES
  (NULL, 'Keyboard Mechanical', 450000.00, 25),
  (NULL, 'Mouse Wireless', 150000.00, 50);

⚠️ Peringatan: Cara ini rawan error jika struktur tabel berubah. Selalu sebutkan nama kolom secara eksplisit agar aman.

INSERT ... ON DUPLICATE KEY UPDATE #

Jika terjadi konflik pada UNIQUE atau PRIMARY KEY, Anda bisa menentukan aksi alternatif:

INSERT INTO pelanggan (nama, email, telepon)
VALUES ('Budi Santoso', 'budi@example.com', '081200000000')
ON DUPLICATE KEY UPDATE telepon = VALUES(telepon);

Jika email sudah ada, telepon akan diperbarui alih-alih menghasilkan error.

INSERT IGNORE #

Mengabaikan error duplikat tanpa menghentikan eksekusi:

INSERT IGNORE INTO pelanggan (nama, email)
VALUES ('Budi Duplikat', 'budi@example.com');

Melihat ID yang Baru Dibuat #

SELECT LAST_INSERT_ID();

Berguna saat Anda perlu mengetahui id dari baris yang baru saja di-INSERT.

Read: Membaca Data dengan SELECT #

SELECT adalah perintah yang paling sering digunakan. Kita akan bahas versi dasarnya di sini; filtering dan sorting akan dibahas di artikel berikutnya.

Sintaks Dasar #

SELECT kolom1, kolom2 FROM nama_tabel;

Memilih Semua Kolom #

SELECT * FROM pelanggan;

Tips: Hindari SELECT * di aplikasi produksi. Sebutkan kolom yang benar-benar dibutuhkan agar lebih efisien dan tidak terpengaruh perubahan struktur tabel.

Memilih Kolom Tertentu #

SELECT nama, email FROM pelanggan;

Memberi Alias pada Kolom #

SELECT nama AS nama_pelanggan, email AS surel FROM pelanggan;

Alias membuat nama kolom di hasil query lebih mudah dibaca, terutama saat melibatkan fungsi atau join.

Memberi Alias pada Tabel #

SELECT p.nama, p.email FROM pelanggan AS p;

Alias tabel sangat berguna saat query melibatkan banyak tabel.

Menggunakan Ekspresi dan Fungsi #

SELECT
  nama,
  CONCAT('+62', telepon) AS telepon_internasional,
  UPPER(email) AS email_besar
FROM pelanggan;

Membatasi Jumlah Baris dengan LIMIT #

SELECT * FROM pelanggan LIMIT 2;

Menampilkan hanya 2 baris pertama.

LIMIT dengan OFFSET (Pagination) #

SELECT * FROM pelanggan LIMIT 2 OFFSET 2;

Menampilkan 2 baris mulai dari baris ke-3. Ini dasar dari pagination di aplikasi web.

Menghitung Jumlah Baris #

SELECT COUNT(*) AS total_pelanggan FROM pelanggan;

Menghilangkan Duplikat dengan DISTINCT #

SELECT DISTINCT status FROM pesanan;

Menampilkan nilai unik dari kolom status.

Update: Mengubah Data dengan UPDATE #

Sintaks Dasar #

UPDATE nama_tabel
SET kolom1 = nilai1, kolom2 = nilai2
WHERE kondisi;

⚠️ Peringatan penting: Selalu sertakan klausa WHERE. Tanpa WHERE, semua baris di tabel akan diubah.

Contoh: Mengubah Satu Kolom #

UPDATE pelanggan
SET telepon = '081211112222'
WHERE id = 1;

Mengubah Beberapa Kolom Sekaligus #

UPDATE pelanggan
SET nama = 'Budi Santoso, S.Kom.', telepon = '081233334444'
WHERE id = 1;

Mengubah Berdasarkan Kondisi Tertentu #

UPDATE produk
SET stok = stok + 10
WHERE harga < 200000;

Query ini menambah stok sebanyak 10 untuk semua produk berharga di bawah 200.000.

Menggunakan WHERE dengan IN #

UPDATE produk
SET stok = 0
WHERE id IN (1, 3, 5);

Melihat Jumlah Baris yang Terpengaruh #

Setelah UPDATE, MySQL melaporkan Rows matched dan Changed. Di aplikasi, Anda bisa mengecek jumlah baris yang terpengaruh melalui API driver masing-masing.

UPDATE dengan Subquery #

UPDATE pesanan
SET total = (
  SELECT SUM(harga_satuan * jumlah)
  FROM detail_pesanan
  WHERE detail_pesanan.pesanan_id = pesanan.id
)
WHERE id = 1;

Delete: Menghapus Data dengan DELETE #

Sintaks Dasar #

DELETE FROM nama_tabel WHERE kondisi;

⚠️ Peringatan penting: Selalu sertakan klausa WHERE. Tanpa WHERE, semua baris di tabel akan dihapus.

Contoh: Menghapus Satu Baris #

DELETE FROM pelanggan WHERE id = 4;

Menghapus Berdasarkan Kondisi #

DELETE FROM produk WHERE stok = 0;

Menghapus dengan IN #

DELETE FROM pelanggan WHERE id IN (2, 3);

Menghapus Berdasarkan Rentang Tanggal #

DELETE FROM pesanan
WHERE dibuat_pada < '2022-01-01';

Menghapus Semua Baris (Hati-hati!) #

DELETE FROM pelanggan;

Ini menghapus semua baris tetapi mempertahankan struktur tabel. Bandingkan dengan TRUNCATE TABLE pelanggan; yang lebih cepat dan me-reset AUTO_INCREMENT.

DELETE dengan LIMIT #

DELETE FROM produk WHERE stok = 0 LIMIT 10;

Menghapus maksimal 10 baris yang cocok.

Mengembalikan Data yang Terhapus? #

DELETE bersifat permanen (kecuali Anda punya backup). Jika ragu, lakukan soft delete dengan menambahkan kolom deleted_at:

ALTER TABLE pelanggan ADD COLUMN deleted_at TIMESTAMP NULL DEFAULT NULL;

-- "Menghapus" data
UPDATE pelanggan SET deleted_at = NOW() WHERE id = 1;

-- Menampilkan hanya data yang belum dihapus
SELECT * FROM pelanggan WHERE deleted_at IS NULL;

Pendekatan ini umum di aplikasi produksi karena memungkinkan pemulihan data.

Praktik Lengkap: Alur CRUD Sederhana #

Mari kita jalankan alur CRUD lengkap pada tabel produk:

1. Create — Tambah Produk #

INSERT INTO produk (nama, harga, stok) VALUES
  ('Monitor 24 inch', 1500000.00, 10),
  ('Headset Gaming', 350000.00, 20);

2. Read — Baca Produk #

SELECT id, nama, harga, stok FROM produk;

Output contoh:

+----+------------------+------------+------+
| id | nama             | harga      | stok |
+----+------------------+------------+------+
|  1 | Monitor 24 inch  | 1500000.00 |   10 |
|  2 | Headset Gaming   |  350000.00 |   20 |
+----+------------------+------------+------+

3. Update — Ubah Stok #

UPDATE produk SET stok = stok - 3 WHERE id = 1;

4. Read — Verifikasi Perubahan #

SELECT id, nama, stok FROM produk WHERE id = 1;

5. Delete — Hapus Produk #

DELETE FROM produk WHERE id = 2;

6. Read — Verifikasi Penghapusan #

SELECT * FROM produk;

Ringkasan #

Operasi Perintah Klausa Penting
Create INSERT INTO VALUES, ON DUPLICATE KEY UPDATE
Read SELECT FROM, LIMIT, OFFSET, DISTINCT, COUNT
Update UPDATE SET, WHERE (wajib!)
Delete DELETE FROM WHERE (wajib!), LIMIT

Poin penting:

  • Selalu sebutkan nama kolom pada INSERT agar aman terhadap perubahan struktur.
  • Hindari SELECT * di aplikasi produksi.
  • Selalu gunakan WHERE pada UPDATE dan DELETE kecuali Anda benar-benar ingin memengaruhi seluruh tabel.
  • Pertimbangkan soft delete (deleted_at) untuk data yang mungkin perlu dipulihkan.

Pada artikel berikutnya, kita akan membahas Filtering & Sorting Data menggunakan WHERE, ORDER BY, LIMIT, LIKE, IN, BETWEEN, dan IS NULL.
