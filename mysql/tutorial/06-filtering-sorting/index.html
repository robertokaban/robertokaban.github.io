Pendahuluan #

Pada artikel CRUD sebelumnya, kita sudah bisa membaca data dengan SELECT. Namun di aplikasi nyata, kita hampir selalu perlu memfilter data (misalnya “tampilkan pesanan hari ini”) dan mengurutkannya (misalnya “urutkan dari harga termahal”). Dua operasi inilah yang dibahas di artikel ini.

Kita akan menggunakan tabel pelanggan, produk, dan pesanan dari skema toko_online. Pastikan Anda sudah mengisi beberapa data contoh agar query bisa diuji.

Asumsi: Anda berada di database toko_online (USE toko_online;).

Memfilter Data dengan WHERE #

Klausa WHERE menentukan baris mana yang akan dikembalikan oleh SELECT, UPDATE, atau DELETE.

Sintaks Dasar #

SELECT kolom FROM nama_tabel WHERE kondisi;

Operator Perbandingan #

Operator Arti
= Sama dengan
<> atau != Tidak sama dengan
> Lebih besar
< Lebih kecil
>= Lebih besar atau sama dengan
<= Lebih kecil atau sama dengan

Contoh:

SELECT * FROM produk WHERE harga > 500000;
SELECT * FROM produk WHERE stok = 0;
SELECT * FROM pelanggan WHERE nama <> 'Budi Santoso';

Menggabungkan Kondisi dengan AND, OR, NOT #

AND — kedua kondisi harus benar:

SELECT * FROM produk
WHERE harga > 100000 AND stok > 0;

OR — salah satu kondisi benar:

SELECT * FROM produk
WHERE harga < 100000 OR stok = 0;

NOT — membalik kondisi:

SELECT * FROM produk
WHERE NOT stok = 0;

Menggunakan Tanda Kurung untuk Prioritas #

AND memiliki prioritas lebih tinggi daripada OR. Gunakan tanda kurung agar logika jelas:

-- Salah: OR dievaluasi setelah AND
SELECT * FROM produk
WHERE harga > 100000 AND stok > 0 OR nama LIKE '%Gaming%';

-- Benar: kelompokkan kondisi dengan jelas
SELECT * FROM produk
WHERE (harga > 100000 AND stok > 0)
   OR nama LIKE '%Gaming%';

Tips: Selalu gunakan tanda kurung saat menggabungkan AND dan OR agar tidak salah logika.

Operator LIKE untuk Pencarian Pola #

LIKE digunakan untuk mencocokkan pola teks. Dua wildcard utama:

Wildcard Arti
% Nol atau lebih karakter
_ Tepat satu karakter

Contoh #

Diawali dengan “Key”:

SELECT * FROM produk WHERE nama LIKE 'Key%';

Diakhiri dengan “Gaming”:

SELECT * FROM produk WHERE nama LIKE '%Gaming';

Mengandung kata “Wireless”:

SELECT * FROM produk WHERE nama LIKE '%Wireless%';

Tepat 5 karakter:

SELECT * FROM pelanggan WHERE nama LIKE '_____';

Karakter kedua adalah “a”:

SELECT * FROM pelanggan WHERE nama LIKE '_a%';

Case Sensitivity #

Secara default, LIKE tidak case-sensitive pada collation utf8mb4_unicode_ci (default). Jika ingin case-sensitive, gunakan COLLATE:

SELECT * FROM produk
WHERE nama COLLATE utf8mb4_bin LIKE '%Gaming%';

Escape Wildcard #

Jika Anda ingin mencari karakter % atau _ secara literal, gunakan ESCAPE:

SELECT * FROM produk WHERE nama LIKE '%\%%' ESCAPE '\';

Query ini mencari nama yang mengandung karakter % literal.

Operator IN dan NOT IN #

IN adalah cara ringkas menulis beberapa nilai OR.

Sintaks #

SELECT * FROM nama_tabel WHERE kolom IN (nilai1, nilai2, ...);

Contoh #

Tanpa IN:

SELECT * FROM produk WHERE id = 1 OR id = 3 OR id = 5;

Dengan IN:

SELECT * FROM produk WHERE id IN (1, 3, 5);

NOT IN — nilai tidak termasuk dalam daftar:

SELECT * FROM produk WHERE id NOT IN (1, 3, 5);

IN dengan string:

SELECT * FROM pelanggan
WHERE email IN ('budi@example.com', 'siti@example.com');

IN dengan subquery:

SELECT * FROM pelanggan
WHERE id IN (
  SELECT pelanggan_id FROM pesanan WHERE total > 1000000
);

⚠️ Peringatan: Hati-hati dengan NOT IN dan nilai NULL. Jika subquery mengembalikan NULL, NOT IN tidak akan mengembalikan baris apa pun. Gunakan NOT EXISTS sebagai alternatif yang lebih aman.

Operator BETWEEN #

BETWEEN digunakan untuk mencocokkan rentang nilai (inklusif).

Sintaks #

SELECT * FROM nama_tabel WHERE kolom BETWEEN nilai_awal AND nilai_akhir;

Contoh #

Rentang harga:

SELECT * FROM produk WHERE harga BETWEEN 100000 AND 500000;

Setara dengan:

SELECT * FROM produk WHERE harga >= 100000 AND harga <= 500000;

Rentang tanggal:

SELECT * FROM pesanan
WHERE dibuat_pada BETWEEN '2022-01-01' AND '2022-12-31';

NOT BETWEEN:

SELECT * FROM produk WHERE harga NOT BETWEEN 100000 AND 500000;

Tips: Untuk kolom DATETIME, BETWEEN '2022-01-01' AND '2022-12-31' tidak mencakup waktu di hari terakhir (karena '2022-12-31' dianggap '2022-12-31 00:00:00'). Gunakan '2022-12-31 23:59:59' atau < '2023-01-01' untuk mencakup seluruh hari.

Menangani NULL dengan IS NULL dan IS NOT NULL #

NULL bukan nilai kosong atau nol — ia adalah ketiadaan nilai. Karena itu, NULL tidak bisa dibandingkan dengan = atau <>.

Salah #

SELECT * FROM pelanggan WHERE telepon = NULL;  -- tidak mengembalikan apa pun

Benar #

SELECT * FROM pelanggan WHERE telepon IS NULL;
SELECT * FROM pelanggan WHERE telepon IS NOT NULL;

NULL dalam Kondisi Logika #

  • NULL = NULL → NULL (bukan TRUE).
  • NULL <> NULL → NULL.
  • NULL AND TRUE → NULL.
  • NULL OR TRUE → TRUE.

Gunakan IS NULL / IS NOT NULL untuk memeriksa NULL, bukan =.

Fungsi Terkait NULL #

IFNULL(kolom, nilai_pengganti) — mengganti NULL dengan nilai lain:

SELECT nama, IFNULL(telepon, 'Tidak ada') AS telepon FROM pelanggan;

COALESCE(kolom1, kolom2, ...) — mengembalikan nilai non-NULL pertama:

SELECT nama, COALESCE(telepon, email, 'Tidak ada kontak') AS kontak
FROM pelanggan;

NULLIF(a, b) — mengembalikan NULL jika a = b:

SELECT NULLIF(stok, 0) FROM produk;

Mengurutkan Data dengan ORDER BY #

ORDER BY mengurutkan hasil query.

Sintaks #

SELECT kolom FROM nama_tabel ORDER BY kolom [ASC|DESC];
  • ASC — menaik (default).
  • DESC — menurun.

Contoh #

Urutkan berdasarkan harga (termurah):

SELECT * FROM produk ORDER BY harga ASC;

Urutkan berdasarkan harga (termahal):

SELECT * FROM produk ORDER BY harga DESC;

Urutkan berdasarkan beberapa kolom:

SELECT * FROM produk
ORDER BY stok DESC, harga ASC;

Query ini mengurutkan berdasarkan stok menurun terlebih dahulu; jika stok sama, diurutkan berdasarkan harga menaik.

Urutkan berdasarkan alias:

SELECT nama, harga * 1.1 AS harga_pajak
FROM produk
ORDER BY harga_pajak DESC;

Urutkan berdasarkan nomor kolom (kurang disarankan):

SELECT nama, harga FROM produk ORDER BY 2 DESC;

Nomor 2 merujuk pada kolom kedua (harga). Cara ini ringkas tetapi rawan error jika urutan kolom berubah.

ORDER BY dengan NULL #

Secara default, NULL dianggap paling kecil. Jadi pada ORDER BY kolom ASC, NULL muncul di awal; pada DESC, di akhir.

Untuk mengontrol posisi NULL:

SELECT * FROM pelanggan
ORDER BY telepon IS NULL, telepon ASC;

Query ini menempatkan baris dengan telepon tidak NULL lebih dulu.

Membatasi Hasil dengan LIMIT dan OFFSET #

LIMIT membatasi jumlah baris yang dikembalikan, sedangkan OFFSET menentukan dari baris ke berapa mulai mengambil.

Sintaks #

SELECT kolom FROM nama_tabel
ORDER BY kolom
LIMIT jumlah OFFSET offset;

Contoh #

5 produk termahal:

SELECT * FROM produk ORDER BY harga DESC LIMIT 5;

Halaman 2 dari pagination (10 per halaman):

SELECT * FROM produk
ORDER BY id
LIMIT 10 OFFSET 10;

OFFSET 10 berarti lewati 10 baris pertama, ambil 10 berikutnya.

Tips: Selalu gunakan ORDER BY bersama LIMIT agar hasil konsisten. Tanpa ORDER BY, urutan baris tidak dijamin.

Menggabungkan Semua: Contoh Query Kompleks #

Berikut contoh query yang menggabungkan WHERE, LIKE, BETWEEN, IN, IS NOT NULL, ORDER BY, dan LIMIT:

SELECT
  id,
  nama,
  harga,
  stok
FROM produk
WHERE harga BETWEEN 100000 AND 2000000
  AND stok > 0
  AND nama LIKE '%Gaming%'
  AND id NOT IN (3, 7)
ORDER BY harga DESC, nama ASC
LIMIT 10;

Penjelasan:

  • Hanya produk dengan harga 100.000–2.000.000.
  • Stok tersedia (> 0).
  • Nama mengandung “Gaming”.
  • Bukan produk dengan id 3 atau 7.
  • Diurutkan dari harga termahal; jika sama, berdasarkan nama.
  • Maksimal 10 hasil.

Contoh dengan NULL #

SELECT nama, IFNULL(telepon, '-') AS telepon
FROM pelanggan
WHERE telepon IS NOT NULL
  AND nama LIKE 'B%'
ORDER BY nama ASC;

Urutan Evaluasi Klausa dalam SELECT #

Penting untuk memahami urutan logis evaluasi klausa (bukan urutan penulisan):

  1. FROM — tentukan tabel sumber.
  2. WHERE — filter baris.
  3. GROUP BY — kelompokkan (dibahas nanti).
  4. HAVING — filter grup (dibahas nanti).
  5. SELECT — pilih kolom dan ekspresi.
  6. ORDER BY — urutkan hasil.
  7. LIMIT / OFFSET — batasi hasil.

Karena WHERE dievaluasi sebelum SELECT, Anda tidak bisa menggunakan alias kolom dari SELECT di WHERE:

-- ERROR: alias harga_pajak belum dikenal di WHERE
SELECT harga * 1.1 AS harga_pajak FROM produk WHERE harga_pajak > 100000;

-- Benar: ulangi ekspresi di WHERE
SELECT harga * 1.1 AS harga_pajak FROM produk WHERE harga * 1.1 > 100000;

Alias bisa digunakan di ORDER BY karena dievaluasi setelah SELECT.

Ringkasan #

Klausa / Operator Fungsi
WHERE Memfilter baris berdasarkan kondisi
AND, OR, NOT Menggabungkan kondisi logika
LIKE Mencocokkan pola teks (%, _)
IN / NOT IN Mencocokkan daftar nilai
BETWEEN Mencocokkan rentang inklusif
IS NULL / IS NOT NULL Memeriksa nilai NULL
ORDER BY Mengurutkan hasil (ASC / DESC)
LIMIT / OFFSET Membatasi jumlah baris & pagination

Poin penting:

  • Gunakan tanda kurung saat menggabungkan AND dan OR.
  • NULL tidak bisa dibandingkan dengan =; gunakan IS NULL.
  • Selalu gunakan ORDER BY bersama LIMIT agar hasil konsisten.
  • WHERE dievaluasi sebelum SELECT, jadi alias tidak bisa dipakai di WHERE.
