Pendahuluan #

PHP adalah bahasa server-side — kode PHP dieksekusi di server, bukan di browser. Agar bisa menjalankan file .php, kita memerlukan PHP runtime dan biasanya web server (Apache atau Nginx).

Berbeda dengan JavaScript yang langsung berjalan di browser, PHP memerlukan instalasi. Untungnya, ada banyak paket instalasi yang menyederhanakan proses ini.

Artikel ini membahas:

  • Instalasi PHP di Windows (via XAMPP — cara termudah).
  • Instalasi PHP di Linux Ubuntu (via APT).
  • Instalasi PHP di macOS (via Homebrew).
  • Menjalankan PHP built-in server untuk development cepat.
  • Verifikasi instalasi dan persiapan editor.

Asumsi: Anda sudah membaca artikel Pengenalan PHP dan memiliki hak administrator di komputer/server.

Memilih Metode Instalasi #

Platform Metode Tingkat Kesulitan Direkomendasikan Untuk
Windows XAMPP Mudah Pemula, development lokal
Windows Manual Sedang Yang butuh kontrol penuh
Ubuntu/Debian APT Mudah Server, development
macOS Homebrew Mudah Development lokal

Tips: Untuk pemula di Windows, XAMPP adalah pilihan paling praktis — sudah termasuk PHP, Apache, MySQL, dan phpMyAdmin dalam satu paket .

Instalasi PHP di Windows (XAMPP) #

XAMPP adalah paket all-in-one yang berisi Apache, MySQL, PHP, dan Perl. Sangat populer untuk development lokal.

Langkah-langkah #

1. Unduh XAMPP Kunjungi https://www.apachefriends.org/index.html, unduh versi Windows. Pilih versi PHP yang diinginkan (disarankan PHP 8.x).

2. Instal XAMPP Jalankan installer dengan hak administrator. Ikuti wizard:

  • Pilih komponen (pastikan Apache, MySQL, dan PHP tercentang).
  • Pilih direktori instalasi (default: C:\xampp).
  • Selesaikan instalasi.

3. Jalankan XAMPP Control Panel Buka xampp-control.exe (disarankan Run as administrator). Klik Start pada modul Apache dan MySQL [citation:5].

4. Verifikasi PHP Buka Command Prompt, arahkan ke folder PHP XAMPP:

cd C:\xampp\php
php -v

Jika berhasil, akan muncul versi PHP, misalnya:

PHP 8.2.12 (cli) (built: Oct 24 2023 12:00:00) (ZTS Visual C++ 2019 x64)

5. Tes dengan Browser Buat file info.php di C:\xampp\htdocs:

<?php
phpinfo();

Buka browser: http://localhost/info.php. Jika muncul halaman informasi PHP, instalasi berhasil .

Konfigurasi php.ini #

File konfigurasi PHP ada di C:\xampp\php\php.ini. Beberapa pengaturan yang sering diubah:

; Tampilkan error saat development
display_errors = On
error_reporting = E_ALL

; Batas upload
upload_max_filesize = 64M
post_max_size = 64M

; Memory limit
memory_limit = 256M

; Timezone
date.timezone = Asia/Jakarta

Setelah mengubah php.ini, restart Apache melalui XAMPP Control Panel agar perubahan berlaku.

Menambahkan PHP ke PATH (Opsional) #

Agar perintah php bisa dijalankan dari folder mana pun:

  1. Buka Environment Variables (cari di Start Menu).
  2. Edit Path → New → masukkan C:\xampp\php.
  3. Simpan, buka Command Prompt baru, uji dengan php -v.

Instalasi PHP di Linux (Ubuntu) #

Di Ubuntu/Debian, PHP tersedia di repositori resmi dan bisa diinstal dengan apt.

Instalasi PHP (Versi Default Repositori) #

sudo apt update
sudo apt install php php-cli php-fpm php-mysql php-curl php-gd php-mbstring php-xml php-zip -y

Perintah di atas menginstal PHP beserta ekstensi yang paling umum digunakan: MySQL, cURL, GD (gambar), mbstring, XML, dan ZIP [citation:2][citation:14].

Instalasi Versi PHP Tertentu (via PPA) #

Jika butuh versi PHP yang lebih baru (misalnya PHP 8.2 atau 8.3), tambahkan PPA Ondřej Surý:

sudo apt install software-properties-common -y
sudo add-apt-repository ppa:ondrej/php
sudo apt update

Lalu instal versi yang diinginkan:

sudo apt install php8.2 php8.2-cli php8.2-fpm php8.2-mysql php8.2-curl php8.2-xml php8.2-mbstring php8.2-zip php8.2-gd -y

Ganti 8.2 dengan versi yang diinginkan [citation:6].

Verifikasi #

php -v

Output contoh:

PHP 8.2.12 (cli) (built: Oct 24 2023 12:00:00) (NTS)

Cek ekstensi yang terpasang:

php -m

Integrasi dengan Web Server #

Apache:

sudo apt install apache2 libapache2-mod-php -y
sudo systemctl restart apache2

Buat file tes di /var/www/html/info.php:

<?php phpinfo();

Akses http://localhost/info.php di browser.

Nginx (PHP-FPM):

sudo apt install nginx php-fpm -y

Edit konfigurasi Nginx (/etc/nginx/sites-available/default), tambahkan:

location ~ \.php$ {
    include snippets/fastcgi-php.conf;
    fastcgi_pass unix:/run/php/php8.2-fpm.sock;
}

Restart:

sudo systemctl restart nginx
sudo systemctl restart php8.2-fpm

Catatan: Untuk development lokal, PHP built-in server (dibahas di bawah) seringkali lebih praktis daripada mengkonfigurasi Apache/Nginx.

Instalasi PHP di macOS (Homebrew) #

Cara termudah di macOS adalah menggunakan Homebrew.

Prasyarat #

Homebrew sudah terpasang. Jika belum, jalankan perintah dari https://brew.sh.

Instalasi #

brew install php

Perintah ini menginstal PHP versi terbaru (saat ini PHP 8.x) [citation:3][citation:9].

Verifikasi #

php -v

Instalasi Versi Tertentu #

Homebrew mendukung beberapa versi PHP. Untuk menginstal versi tertentu (misalnya PHP 8.2):

brew install php@8.2

Untuk beralih versi:

brew unlink php
brew link --overwrite php@8.2

Menjalankan PHP-FPM (Opsional) #

Jika ingin menggunakan Nginx atau Apache di macOS:

brew services start php

PHP Built-in Server (Development Cepat) #

Sejak PHP 5.4, PHP memiliki built-in web server — sangat praktis untuk development tanpa perlu menginstal Apache/Nginx.

Menjalankan #

Masuk ke direktori proyek Anda, lalu:

php -S localhost:8000

Buka browser: http://localhost:8000. PHP akan menyajikan file dari direktori saat ini.

Dengan Document Root Tertentu #

php -S localhost:8000 -t public/

Perintah ini menjadikan folder public/ sebagai document root.

Router Script (untuk aplikasi dengan routing) #

Jika aplikasi Anda menggunakan front controller (seperti Laravel atau Symfony):

php -S localhost:8000 -t public/ public/index.php

Peringatan: Built-in server hanya untuk development. Jangan gunakan di produksi — tidak dirancang untuk beban tinggi atau keamanan.

Verifikasi Instalasi #

Setelah instalasi, lakukan verifikasi berikut:

1. Cek Versi PHP #

php -v

2. Cek Ekstensi #

php -m

Pastikan ekstensi penting ada: mysqli, pdo_mysql, curl, mbstring, gd, zip.

3. Tes Script PHP Pertama #

Buat file hello.php:

<?php
echo "Hello, PHP!";
echo "<br>";
echo "Versi PHP: " . phpversion();

Jalankan dengan built-in server:

php -S localhost:8000

Atau jika menggunakan XAMPP, letakkan di htdocs dan akses via http://localhost/hello.php.

4. Cek Konfigurasi PHP #

Buat file info.php:

<?php phpinfo();

Buka di browser. Halaman ini menampilkan semua konfigurasi PHP, termasuk Loaded Configuration File (lokasi php.ini), ekstensi, dan setting lainnya.

Tips: Setelah verifikasi, hapus file info.php dari server produksi — informasi di dalamnya bisa disalahgunakan.

Persiapan Editor: VS Code #

Visual Studio Code adalah editor gratis yang sangat populer untuk PHP.

Extension yang Direkomendasikan #

Extension Fungsi
PHP Intelephense Autocomplete, go-to-definition, refactoring
PHP Debug Debugging dengan Xdebug
PHP DocBlocker Generate PHPDoc otomatis
Composer Integrasi Composer
DotENV Syntax highlighting .env

Konfigurasi settings.json #

{
  "php.validate.executablePath": "C:/xampp/php/php.exe",
  "editor.formatOnSave": true,
  "editor.tabSize": 4,
  "files.associations": {
    "*.php": "php"
  }
}

Sesuaikan php.validate.executablePath dengan lokasi PHP di sistem Anda (Windows: C:/xampp/php/php.exe, Linux/macOS: /usr/bin/php).

Debugging dengan Xdebug (Opsional) #

Untuk debugging yang lebih powerful (breakpoint, step-through), instal Xdebug:

Windows (XAMPP):

  1. Unduh Xdebug dari https://xdebug.org/wizard (paste output phpinfo()).
  2. Letakkan file .dll di C:\xampp\php\ext.
  3. Tambahkan di php.ini:
[Xdebug]
zend_extension = "C:\xampp\php\ext\php_xdebug.dll"
xdebug.mode = debug
xdebug.start_with_request = yes
  1. Restart Apache.

Linux:

sudo apt install php-xdebug -y

Konfigurasi di php.ini atau file terpisah di /etc/php/8.x/mods-available/xdebug.ini.

Struktur Proyek PHP Sederhana #

Untuk memulai, buat struktur folder seperti ini:

proyek-php/
├── public/              # Document root (yang diakses browser)
│   ├── index.php
│   └── assets/
│       ├── css/
│       └── js/
├── src/                 # Kode aplikasi
│   └── functions.php
├── config/              # Konfigurasi
│   └── database.php
├── vendor/              # Composer dependencies (nanti)
└── .gitignore

public/index.php:

<?php
require __DIR__ . '/../src/functions.php';

echo "Selamat datang di aplikasi PHP!";

.gitignore:

vendor/
.env
*.log

Tips: Menempatkan file yang diakses browser di folder public/ adalah praktik keamanan yang baik — file konfigurasi dan kode internal tidak bisa diakses langsung via URL.

Ringkasan #

Platform Metode Perintah Kunci
Windows XAMPP Unduh, instal, start Apache di Control Panel
Ubuntu APT sudo apt install php php-mysql php-curl ...
macOS Homebrew brew install php
Semua Built-in server php -S localhost:8000

Poin penting:

  • XAMPP adalah cara termudah di Windows — sudah termasuk Apache, MySQL, PHP.
  • Di Ubuntu, gunakan APT; untuk versi terbaru, tambahkan PPA Ondřej Surý.
  • Di macOS, gunakan Homebrew: brew install php.
  • PHP built-in server (php -S) sangat praktis untuk development — tidak perlu Apache/Nginx.
  • Verifikasi instalasi dengan php -v dan file phpinfo().
  • Restart web server setelah mengubah php.ini.
  • Gunakan VS Code + PHP Intelephense untuk produktivitas.
  • Hapus info.php dari server produksi.
  • Struktur proyek dengan folder public/ meningkatkan keamanan.
