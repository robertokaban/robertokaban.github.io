Pendahuluan #

Setelah lingkungan PHP siap, saatnya menulis kode. Artikel ini membahas fondasi sintaks PHP: cara menyisipkan kode PHP ke HTML, mendeklarasikan variabel, mengenal tipe data, menggunakan operator, dan mendefinisikan konstanta.

PHP adalah bahasa yang loosely typed — tipe data variabel ditentukan otomatis berdasarkan nilai yang diberikan, dan bisa berubah saat runtime. Ini mirip JavaScript, tetapi dengan sintaks yang berbeda.

Asumsi: Anda sudah menginstal PHP dan bisa menjalankan file .php (dari artikel sebelumnya).

Tag PHP #

Kode PHP harus berada di dalam tag PHP agar diproses oleh server. Ada beberapa cara:

1. Tag Standar (Rekomendasikan) #

<?php
echo "Hello, PHP!";
?>

Atau tanpa tag penutup (jika file hanya berisi PHP):

<?php
echo "Hello, PHP!";

Tips: Untuk file yang hanya berisi kode PHP (tanpa HTML), hilangkan tag penutup ?>. Ini mencegah output tak sengaja (misalnya spasi atau newline setelah ?>) yang bisa menyebabkan error “headers already sent”.

2. Tag Echo Singkat #

<?= "Hello, PHP!" ?>

<?= adalah singkatan dari <?php echo. Selalu tersedia sejak PHP 5.4, terlepas dari setting short_open_tag.

3. Tag Pendek (Hindari) #

<? echo "Hello"; ?>

Membutuhkan short_open_tag = On di php.ini. Hindari karena tidak selalu tersedia.

4. Tag ASP (Hindari) #

<% echo "Hello"; %>

Membutuhkan asp_tags = On (dihapus di PHP 7). Jangan gunakan.

Menyisipkan PHP ke HTML #

PHP bisa disisipkan di mana saja dalam HTML:

<!DOCTYPE html>
<html>
<head>
  <title>Latihan PHP</title>
</head>
<body>
  <h1><?php echo "Halo dari PHP!"; ?></h1>

  <?php if (date("H") < 12): ?>
    <p>Selamat pagi!</p>
  <?php else: ?>
    <p>Selamat siang!</p>
  <?php endif; ?>
</body>
</html>

Komentar #

<?php
// Komentar satu baris (C++ style)

# Komentar satu baris (shell style)

/*
  Komentar
  multi-baris
*/

/**
 * Komentar PHPDoc — untuk dokumentasi fungsi/class
 * @param string $nama
 * @return string
 */
function sapa($nama) {
    return "Halo, $nama!";
}

Tips: Gunakan // untuk komentar singkat dan /* */ untuk komentar multi-baris atau menonaktifkan blok kode sementara.

Statement dan Ekspresi #

Setiap statement PHP diakhiri titik koma (;). Berbeda dengan JavaScript, titik koma di PHP wajib (tidak ada ASI).

<?php
$x = 5;           // statement
$y = $x + 3;      // statement
echo $y;          // statement

Variabel #

Deklarasi Variabel #

Variabel di PHP diawali tanda dolar ($), diikuti nama variabel. Tidak perlu kata kunci let/const.

<?php
$nama = "Budi";
$umur = 25;
$aktif = true;

echo $nama;  // "Budi"
echo $umur;  // 25

Aturan Penamaan Variabel #

  1. Diawali huruf atau underscore — tidak boleh angka.

    $nama = "Budi";     // ✅
$_private = 1;      // ✅
$1nama = "Budi";    // ❌ ParseError

  2. Hanya berisi huruf, angka, dan underscore — tanpa spasi atau karakter khusus.

    $nama_lengkap = "Budi";  // ✅
$nama-lengkap = "Budi";  // ❌ (dianggap pengurangan)

  3. Case-sensitive — $nama dan $Nama adalah variabel berbeda.

  4. Tidak boleh menggunakan reserved words — seperti $this, $GLOBALS, dll.

Convention #

Gaya Contoh Digunakan Untuk
camelCase $namaLengkap, $totalHarga Variabel & fungsi (PSR-12)
snake_case $nama_lengkap, $total_harga Variabel (WordPress, Laravel)
UPPER_SNAKE_CASE MAX_SIZE, API_URL Konstanta

Rekomendasi: Ikuti PSR-12 — gunakan camelCase untuk variabel dan method, PascalCase untuk class, UPPER_SNAKE_CASE untuk konstanta.

Variable Variables #

PHP mendukung variable variables — nama variabel diambil dari nilai variabel lain.

<?php
$nama = "Budi";
$$nama = "Santoso";  // membuat variabel $Budi

echo $Budi;  // "Santoso"

⚠️ Peringatan: Fitur ini jarang dipakai dan bisa membingungkan. Hindari kecuali benar-benar perlu.

Variabel Global dan $GLOBALS #

Variabel yang dideklarasikan di luar fungsi memiliki global scope. Untuk mengaksesnya di dalam fungsi, gunakan kata kunci global atau array $GLOBALS.

<?php
$x = 10;

function tampilkan() {
    global $x;
    echo $x;  // 10
}

function tampilkan2() {
    echo $GLOBALS['x'];  // 10
}

tampilkan();
tampilkan2();

Tips: Hindari variabel global sebisa mungkin — sulit dilacak dan menyebabkan bug. Gunakan parameter fungsi atau dependency injection.

Tipe Data #

PHP mendukung beberapa tipe data:

1. String #

Teks, diapit single quote (') atau double quote (").

<?php
$nama1 = 'Budi';
$nama2 = "Andi";

echo $nama1;  // "Budi"

Perbedaan single vs double quote:

<?php
$nama = "Budi";

echo 'Halo, $nama!';  // "Halo, $nama!" (tidak diinterpolasi)
echo "Halo, $nama!";  // "Halo, Budi!" (diinterpolasi)

// Double quote mendukung escape character
echo "Baris 1\nBaris 2";  // newline
echo "Tab\tDi sini";      // tab

// Single quote hanya escape \' dan \\
echo 'It\'s okay';        // "It's okay"

Heredoc dan Nowdoc:

<?php
$nama = "Budi";

// Heredoc — seperti double quote, mendukung interpolasi
$teks1 = <<<EOT
Halo, $nama!
Ini multi-baris.
EOT;

// Nowdoc — seperti single quote, tidak ada interpolasi
$teks2 = <<<'EOT'
Halo, $nama!
Ini multi-baris.
EOT;

echo $teks1;  // "Halo, Budi!..."
echo $teks2;  // "Halo, $nama!..."

2. Integer #

Bilangan bulat (tanpa desimal).

<?php
$umur = 25;
$negatif = -10;
$besar = 1_000_000;  // separator underscore (PHP 7.4+)

// Basis bilangan
$desimal = 255;
$heksadesimal = 0xFF;   // 255
$oktal = 0755;          // 493
$biner = 0b11111111;    // 255

echo $umur;  // 25

3. Float (Double) #

Bilangan desimal.

<?php
$pi = 3.14;
$suhu = -2.5;
$besar = 1.5e3;  // 1500

echo $pi;  // 3.14

// Cek tipe
var_dump($pi);  // float(3.14)

Nilai khusus:

<?php
var_dump(1 / 0);         // Fatal error di PHP 8 (DivisionByZeroError)
var_dump(fdiv(1, 0));    // float(INF)
var_dump(fdiv(0, 0));    // float(NAN)
var_dump(is_nan(NAN));   // bool(true)
var_dump(is_infinite(fdiv(1, 0))); // bool(true)

Catatan: Di PHP 8, 1 / 0 melempar DivisionByZeroError. Gunakan fdiv() untuk mendapatkan INF/NAN.

4. Boolean #

true atau false.

<?php
$aktif = true;
$selesai = false;

var_dump($aktif);  // bool(true)

// Konversi ke boolean
var_dump((bool) 0);       // bool(false)
var_dump((bool) 1);       // bool(true)
var_dump((bool) "");      // bool(false)
var_dump((bool) "0");     // bool(false) — beda dengan JS!
var_dump((bool) "Hello"); // bool(true)
var_dump((bool) []);      // bool(false)
var_dump((bool) [0]);     // bool(true)
var_dump((bool) null);    // bool(false)

Truthy/Falsy di PHP:

Falsy Truthy
false true
0, 0.0, -0 Angka selain 0
"", "0" String selain "" dan "0"
[] (array kosong) Array berisi elemen
null Object, resource

⚠️ Peringatan: Di PHP, string "0" adalah falsy — berbeda dengan JavaScript! Ini sering menjadi sumber bug.

5. Null #

Menandakan variabel tanpa nilai.

<?php
$user = null;

var_dump($user);       // NULL
var_dump(is_null($user)); // bool(true)
var_dump($user === null); // bool(true)

// Null coalescing
$nama = $user ?? "Anonim";  // "Anonim"

6. Array #

PHP memiliki array yang bisa berfungsi sebagai list (indexed) maupun map (associative). Dibahas detail di artikel Array.

<?php
$buah = ["apel", "jeruk", "mangga"];           // indexed
$user = ["nama" => "Budi", "umur" => 25];       // associative
$nested = [[1, 2], [3, 4]];                     // multidimensional

7. Object #

Instance dari class. Dibahas detail di artikel OOP.

<?php
class User {
    public $nama;
    public function __construct($nama) {
        $this->nama = $nama;
    }
}

$user = new User("Budi");
echo $user->nama;  // "Budi"

8. Resource #

Referensi ke sumber daya eksternal (file handle, koneksi database). Jarang disentuh langsung.

<?php
$file = fopen("data.txt", "r");
var_dump($file);  // resource(5) of type (stream)
fclose($file);

Ringkasan Tipe Data #

Tipe Contoh gettype()
string "Hello" "string"
int 42 "integer"
float 3.14 "double"
bool true "boolean"
null null "NULL"
array [1, 2, 3] "array"
object new User() "object"
resource fopen(...) "resource"

Mengecek Tipe Data #

var_dump() — Informasi Lengkap #

<?php
var_dump("Hello");   // string(5) "Hello"
var_dump(42);        // int(42)
var_dump(3.14);      // float(3.14)
var_dump(true);      // bool(true)
var_dump(null);      // NULL
var_dump([1, 2, 3]); // array(3) { [0]=> int(1) ... }

gettype() — Nama Tipe #

<?php
echo gettype("Hello");  // "string"
echo gettype(42);       // "integer"
echo gettype(3.14);     // "double"
echo gettype(true);     // "boolean"
echo gettype(null);     // "NULL"
echo gettype([]);       // "array"

is_* Functions #

<?php
var_dump(is_string("Hello"));  // bool(true)
var_dump(is_int(42));          // bool(true)
var_dump(is_float(3.14));      // bool(true)
var_dump(is_bool(true));       // bool(true)
var_dump(is_null(null));       // bool(true)
var_dump(is_array([]));        // bool(true)
var_dump(is_object(new stdClass())); // bool(true)
var_dump(is_numeric("42"));    // bool(true) — string angka
var_dump(is_numeric("abc"));   // bool(false)

Operator #

1. Operator Aritmatika #

<?php
$a = 10;
$b = 3;

echo $a + $b;   // 13
echo $a - $b;   // 7
echo $a * $b;   // 30
echo $a / $b;   // 3.3333...
echo $a % $b;   // 1
echo $a ** $b;  // 1000 (pangkat)

Catatan: Pembagian / selalu menghasilkan float jika tidak habis dibagi. Gunakan intdiv() untuk pembagian integer.

<?php
echo intdiv(10, 3);  // 3
echo 10 % 3;         // 1

2. Operator Penugasan #

<?php
$x = 10;
$x += 5;   // 15
$x -= 3;   // 12
$x *= 2;   // 24
$x /= 4;   // 6
$x %= 4;   // 2
$x **= 3;  // 8

Null coalescing assignment (??=) (PHP 7.4+):

<?php
$nama = null;
$nama ??= "Anonim";  // $nama = "Anonim" jika null
echo $nama;  // "Anonim"

3. Operator Increment/Decrement #

<?php
$counter = 0;
$counter++;    // 1 (post-increment)
$counter--;    // 0
++$counter;    // 1 (pre-increment)
--$counter;    // 0

// Perbedaan pre dan post
$x = 5;
echo $x++;  // 5 (kembalikan 5, lalu x jadi 6)
echo $x;    // 6

$y = 5;
echo ++$y;  // 6 (y jadi 6 dulu, lalu kembalikan 6)

4. Operator Perbandingan #

Operator Arti Contoh Hasil
== Sama (longgar, dengan konversi tipe) 5 == "5" true
=== Sama (ketat, tanpa konversi) 5 === "5" false
!= Tidak sama (longgar) 5 != "5" false
!== Tidak sama (ketat) 5 !== "5" true
> Lebih besar 5 > 3 true
< Lebih kecil 5 < 3 false
>= Lebih besar atau sama 5 >= 5 true
<= Lebih kecil atau sama 5 <= 3 false
<=> Spaceship — -1, 0, 1 5 <=> 3 1

Selalu gunakan === dan !== — hindari == karena konversi tipe yang tidak terduga:

<?php
var_dump(0 == "");        // bool(true)  (!!)
var_dump(0 == "0");       // bool(true)
var_dump("" == "0");      // bool(false)
var_dump(null == false);  // bool(true)
var_dump(null === false); // bool(false)

// Spaceship operator
var_dump(5 <=> 3);  // int(1)
var_dump(5 <=> 5);  // int(0)
var_dump(3 <=> 5);  // int(-1)

5. Operator Logika #

Operator Arti Contoh
&& AND true && false → false
|| OR true || false → true
! NOT !true → false
and AND (prioritas lebih rendah) $a and $b
or OR (prioritas lebih rendah) $a or $b
xor XOR $a xor $b

Catatan: && dan || memiliki prioritas lebih tinggi daripada and dan or. Dalam kebanyakan kasus, gunakan && dan ||.

6. Operator String #

<?php
$nama = "Budi";
$sapaan = "Halo, " . $nama . "!";  // concatenation
echo $sapaan;  // "Halo, Budi!"

// Concatenation assignment
$teks = "Hello";
$teks .= " World";
echo $teks;  // "Hello World"

7. Operator Ternary #

<?php
$umur = 20;
$status = $umur >= 18 ? "Dewasa" : "Anak-anak";
echo $status;  // "Dewasa"

// Ternary singkat (PHP 5.3+, deprecated di PHP 7.4, dihapus di PHP 8)
// $status = $umur ?: "Anonim";  // ❌

// Null coalescing (pengganti yang aman)
$nama = $userInput ?? "Anonim";

8. Operator Null Coalescing (??) #

Mengembalikan operand kanan jika operand kiri null atau tidak ada (undefined).

<?php
$nama = $_GET['nama'] ?? "Anonim";
echo $nama;

// Chaining
$nilai = $a ?? $b ?? $c ?? "default";

Tips: ?? berbeda dengan ?: (ternary singkat). ?? hanya mengecek null/undefined, sedangkan ?: mengecek truthy/falsy.

9. Operator Nullsafe (?->) — PHP 8+ #

Mengakses properti/method dengan aman — jika object null, hasilnya null alih-alih error.

<?php
$user = getUser(); // mungkin null
echo $user?->nama ?? "Anonim";

10. Operator instanceof #

Mengecek apakah object adalah instance dari class tertentu.

<?php
class User {}
$user = new User();

var_dump($user instanceof User);  // bool(true)

Konstanta #

Konstanta adalah nilai yang tidak bisa diubah setelah didefinisikan.

define() #

<?php
define("PI", 3.14159);
define("APP_NAME", "Toko Online");
define("MAX_LOGIN_ATTEMPTS", 5);

echo PI;          // 3.14159
echo APP_NAME;    // "Toko Online"

// PI = 3.14;  // ❌ Error — konstanta tidak bisa diubah

const (PHP 5.3+, di luar class) #

<?php
const PI = 3.14159;
const APP_NAME = "Toko Online";

Perbedaan define() vs const:

Aspek define() const
Didefinisikan di Runtime Compile-time
Bisa di dalam if? ✅ ❌ (harus top-level)
Bisa di dalam class? ❌ ✅
Nama dinamis? ✅ ❌
Kecepatan Lebih lambat Lebih cepat

Konstanta Class #

<?php
class Config {
    const APP_NAME = "Toko Online";
    const VERSION = "1.0.0";
}

echo Config::APP_NAME;   // "Toko Online"
echo Config::VERSION;    // "1.0.0"

Konstanta Magic #

PHP menyediakan konstanta “magic” yang nilainya berubah tergantung konteks:

Konstanta Arti
__LINE__ Nomor baris saat ini
__FILE__ Path lengkap file
__DIR__ Direktori file
__FUNCTION__ Nama fungsi
__CLASS__ Nama class
__METHOD__ Nama method (Class::method)
__NAMESPACE__ Nama namespace 
<?php
echo __LINE__;   // nomor baris
echo __FILE__;   // "/var/www/html/index.php"
echo __DIR__;    // "/var/www/html"

Cek Konstanta #

<?php
define("APP_NAME", "Toko Online");

var_dump(defined("APP_NAME"));  // bool(true)
var_dump(defined("TIDAK_ADA")); // bool(false)

Contoh Praktis: Menghitung Total Belanja #

Mari gabungkan semua yang telah dipelajari:

<?php
// Konstanta
const HARGA_PRODUK = 150000;
const DISKON_PERSEN = 10;
const MINIMAL_GRATIS_ONGKIR = 300000;

// Variabel
$jumlahBeli = 3;
$totalSebelumDiskon = HARGA_PRODUK * $jumlahBeli;
$nilaiDiskon = $totalSebelumDiskon * (DISKON_PERSEN / 100);
$totalAkhir = $totalSebelumDiskon - $nilaiDiskon;

// Cek gratis ongkir
$gratisOngkir = $totalAkhir >= MINIMAL_GRATIS_ONGKIR;

// Output
echo "Jumlah beli: $jumlahBeli\n";
echo "Total sebelum diskon: Rp" . number_format($totalSebelumDiskon, 0, ",", ".") . "\n";
echo "Diskon (" . DISKON_PERSEN . "%): Rp" . number_format($nilaiDiskon, 0, ",", ".") . "\n";
echo "Total akhir: Rp" . number_format($totalAkhir, 0, ",", ".") . "\n";
echo "Gratis ongkir: " . ($gratisOngkir ? "Ya" : "Tidak") . "\n";

Output:

Jumlah beli: 3
Total sebelum diskon: Rp450.000
Diskon (10%): Rp45.000
Total akhir: Rp405.000
Gratis ongkir: Ya

Ringkasan #

Konsep Poin Penting
Tag PHP <?php ... ?>, <?= ... ?>
Variabel Diawali $, case-sensitive, loosely typed
String Single quote (literal), double quote (interpolasi)
Integer Bilangan bulat, bisa heksadesimal/oktal/biner
Float Bilangan desimal, INF/NAN via fdiv()
Boolean true/false; "0" adalah falsy (beda dengan JS!)
Null null, cek dengan is_null(), ??
Array List & map dalam satu tipe
var_dump Info lengkap tipe & nilai
gettype Nama tipe
is_* Cek tipe
=== vs == Selalu gunakan === (strict)
?? Null coalescing
?-> Nullsafe (PHP 8+)
define / const Konstanta

Poin penting:

  • Titik koma wajib di akhir statement.
  • Hilangkan ?> di file yang hanya berisi PHP.
  • Variabel diawali $ — case-sensitive.
  • String "0" adalah falsy di PHP (beda dengan JavaScript).
  • Selalu gunakan === dan !== untuk perbandingan.
  • ?? hanya mengecek null, berbeda dengan ?: yang mengecek truthy/falsy.
  • Gunakan const untuk konstanta di top-level, define() jika butuh dinamis.
  • Hindari variabel global — gunakan parameter atau dependency injection.
