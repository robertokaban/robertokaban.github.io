Pendahuluan #

Pada artikel sebelumnya kita sudah mengenal tipe data PHP secara singkat. Sekarang kita akan membahasnya lebih mendalam — terutama konversi tipe (type juggling) yang menjadi sumber bug paling umum di PHP.

PHP adalah bahasa loosely typed (atau dynamically typed) — variabel tidak memiliki tipe tetap, dan PHP otomatis mengonversi tipe dalam banyak situasi. Fleksibilitas ini memudahkan penulisan kode, tetapi juga bisa mengejutkan jika tidak dipahami.

Artikel ini membahas:

  • Tipe data primitif secara mendalam.
  • Cara mengecek tipe.
  • Konversi implisit (type juggling).
  • Konversi eksplisit (casting).
  • Perbandingan longgar (==) vs ketat (===).
  • Best practice.

Asumsi: Anda sudah memahami sintaks dasar, variabel, dan operator dari artikel sebelumnya.

Tipe Data Primitif #

PHP memiliki beberapa tipe data primitif:

Tipe gettype() Contoh
string "string" "Hello"
int "integer" 42
float "double" 3.14
bool "boolean" true
null "NULL" null
array "array" [1, 2, 3]
object "object" new User()
resource "resource" fopen(...)

String #

Membuat String #

<?php
$single = 'Hello';
$double = "Hello";
$heredoc = <<<EOT
Hello, World!
EOT;
$nowdoc = <<<'EOT'
Hello, World!
EOT;

Perbedaan Single vs Double Quote #

Aspek Single Quote '...' Double Quote "..."
Interpolasi variabel ❌ ✅
Escape \n, \t ❌ (literal) ✅
Escape \' ✅ ❌ (pakai \")
Performa Sedikit lebih cepat Sedikit lebih lambat 
<?php
$nama = "Budi";

echo 'Halo, $nama!';   // "Halo, $nama!" (literal)
echo "Halo, $nama!";   // "Halo, Budi!" (interpolasi)
echo "Halo, {$nama}!"; // "Halo, Budi!" (kurung kurawal)

Tips: Gunakan single quote untuk string statis (performa lebih baik), double quote jika butuh interpolasi.

Interpolasi Kompleks #

<?php
$user = ["nama" => "Budi", "umur" => 25];

// ❌ Error — array tidak bisa diinterpolasi langsung
// echo "Nama: $user['nama']";

// ✅ Gunakan kurung kurawal
echo "Nama: {$user['nama']}, Umur: {$user['umur']}";

// Atau concatenation
echo "Nama: " . $user['nama'];

Fungsi String Umum #

<?php
$teks = "  Hello World  ";

echo strlen($teks);              // 15 (termasuk spasi)
echo trim($teks);                // "Hello World"
echo strtoupper($teks);          // "  HELLO WORLD  "
echo strtolower($teks);          // "  hello world  "
echo str_replace("World", "PHP", $teks); // "  Hello PHP  "
echo substr($teks, 2, 5);        // "Hello"
echo strpos($teks, "World");     // 8
echo str_contains($teks, "World"); // true (PHP 8+)
echo str_starts_with($teks, "  H"); // true (PHP 8+)
echo str_ends_with($teks, "  ");    // true (PHP 8+)
echo ucfirst("hello");           // "Hello"
echo ucwords("hello world");     // "Hello World"
echo str_repeat("ab", 3);        // "ababab"
echo str_pad("5", 3, "0", STR_PAD_LEFT); // "005"
echo nl2br("Baris 1\nBaris 2");  // "Baris 1<br />Baris 2"
echo number_format(1500000, 0, ",", "."); // "1.500.000"
echo sprintf("Halo, %s! Umur %d", "Budi", 25); // "Halo, Budi! Umur 25"

Multibyte String #

Untuk karakter Unicode (misalnya emoji, huruf non-Latin), gunakan mb_* functions:

<?php
$teks = "Halo, 世界!";

echo strlen($teks);       // 13 (byte)
echo mb_strlen($teks);    // 10 (karakter)
echo mb_substr($teks, 0, 5); // "Halo,"

Tips: Jika aplikasi Anda menangani teks non-ASCII, selalu gunakan mb_* functions dan set default_charset = "UTF-8" di php.ini.

Integer #

Rentang Integer #

Bergantung pada platform (32-bit vs 64-bit):

Platform Nilai Maksimum
32-bit 2.147.483.647 (PHP_INT_MAX)
64-bit 9.223.372.036.854.775.807 
<?php
echo PHP_INT_MAX;   // 9223372036854775807 (64-bit)
echo PHP_INT_MIN;   // -9223372036854775808
echo PHP_INT_SIZE;  // 8 (byte, 64-bit)

Overflow #

Jika hasil operasi melebihi PHP_INT_MAX, PHP otomatis mengonversi ke float:

<?php
var_dump(PHP_INT_MAX + 1);  // float(9.2233720368548E+18)

⚠️ Peringatan: Overflow bisa menyebabkan kehilangan presisi. Untuk angka sangat besar, gunakan BCMath (bcadd, bcmul, dll.) atau GMP.

Cek Integer #

<?php
var_dump(is_int(42));      // bool(true)
var_dump(is_int("42"));    // bool(false) — string!
var_dump(is_integer(42));  // bool(true) — alias
var_dump(is_long(42));     // bool(true) — alias

// PHP 8+: cek tipe dari input
var_dump(filter_var("42", FILTER_VALIDATE_INT));     // int(42)
var_dump(filter_var("abc", FILTER_VALIDATE_INT));    // bool(false)

Float #

Presisi Float #

Float di PHP mengikuti standar IEEE 754 double precision (64-bit). Ini menyebabkan masalah presisi yang sama dengan JavaScript:

<?php
var_dump(0.1 + 0.2);           // float(0.30000000000000004)
var_dump(0.1 + 0.2 === 0.3);   // bool(false) (!!)

// Bandingkan dengan toleransi
$epsilon = 1e-10;
var_dump(abs((0.1 + 0.2) - 0.3) < $epsilon); // bool(true)

Tips: Untuk uang, jangan gunakan float. Gunakan integer (dalam sen) atau string dengan BCMath.

<?php
// ❌ Buruk untuk uang
$harga = 0.1 + 0.2;  // 0.30000000000000004

// ✅ Baik — integer (dalam sen)
$hargaSen = 10 + 20;  // 30 (Rp0,30)
echo number_format($hargaSen / 100, 2);  // "0.30"

// ✅ Baik — BCMath
echo bcadd("0.1", "0.2", 2);  // "0.30"

NAN dan INF #

<?php
$inf = fdiv(1, 0);    // INF
$nan = fdiv(0, 0);    // NAN

var_dump(is_infinite($inf));  // bool(true)
var_dump(is_nan($nan));       // bool(true)
var_dump(is_finite(3.14));    // bool(true)

// NAN tidak sama dengan dirinya sendiri
var_dump($nan === $nan);      // bool(false)

Cek Float #

<?php
var_dump(is_float(3.14));    // bool(true)
var_dump(is_float(42));      // bool(false) — int
var_dump(is_double(3.14));   // bool(true) — alias
var_dump(is_real(3.14));     // bool(true) — alias

Boolean #

Nilai Boolean #

Hanya true dan false (case-insensitive: TRUE, True, true).

<?php
$aktif = true;
$selesai = false;

var_dump($aktif);   // bool(true)
var_dump($selesai); // bool(false)

Konversi ke Boolean (Truthy/Falsy) #

Saat nilai non-boolean digunakan dalam konteks boolean (misalnya if), PHP mengonversinya:

Nilai Boolean
false false
0 (int) false
0.0 (float) false
-0.0 (float) false
"" (string kosong) false
"0" (string nol) false ⚠️
[] (array kosong) false
null false
"0.0" true
"false" true
" " (spasi) true
-1 true
[] dengan elemen true
new stdClass() true

⚠️ Peringatan penting: String "0" adalah falsy di PHP! Ini berbeda dengan JavaScript, di mana "0" adalah truthy. Ini sering menjadi sumber bug.

<?php
if ("0") {
    echo "Truthy";  // TIDAK dijalankan
} else {
    echo "Falsy";   // Dijalankan
}

Cek Boolean #

<?php
var_dump(is_bool(true));   // bool(true)
var_dump(is_bool(1));      // bool(false) — int
var_dump(is_bool("true")); // bool(false) — string

Konversi Eksplisit ke Boolean #

<?php
var_dump((bool) 0);       // bool(false)
var_dump((bool) 1);       // bool(true)
var_dump((bool) "");      // bool(false)
var_dump((bool) "0");     // bool(false)
var_dump((bool) "0.0");   // bool(true)
var_dump((bool) "false"); // bool(true)
var_dump((bool) []);      // bool(false)
var_dump((bool) [0]);     // bool(true)
var_dump((bool) null);    // bool(false)
var_dump(boolval("0"));   // bool(false) — fungsi alternatif

Null #

Karakteristik #

  • null adalah tipe khusus dengan satu nilai: null (case-insensitive).
  • Variabel dianggap null jika:
    • Di-assign null secara eksplisit.
    • Belum pernah di-assign.
    • Di-unset().
<?php
$nama = null;
var_dump($nama);       // NULL
var_dump(is_null($nama)); // bool(true)
var_dump($nama === null); // bool(true)

// Variabel yang belum di-assign
var_dump($undefined);  // Warning: Undefined variable + NULL

unset() #

<?php
$x = 10;
unset($x);
var_dump(isset($x));  // bool(false)

Cek Null #

<?php
$nama = null;

var_dump(is_null($nama));      // bool(true)
var_dump($nama === null);      // bool(true)
var_dump(isset($nama));        // bool(false) — isset() false untuk null
var_dump(isset($nama) && $nama !== null); // bool(false)

isset() vs is_null():

Aspek isset($x) is_null($x)
$x = null false true
$x tidak didefinisikan false (tanpa warning) true (dengan warning)
$x = 0 true false

Tips: Gunakan isset() untuk mengecek apakah variabel ada dan tidak null. Gunakan array_key_exists() untuk mengecek key array yang mungkin bernilai null.

Null Coalescing #

<?php
$nama = $userInput ?? "Anonim";        // jika null/undefined
$nama = $userInput ?: "Anonim";        // jika falsy (termasuk "0")
$nama = $userInput ?? $namaDefault ?? "Anonim"; // chaining

Array #

Array di PHP adalah struktur yang sangat fleksibel — berfungsi sebagai list (indexed) maupun map (associative). Detailnya dibahas di artikel Array, tetapi berikut ringkasan tipenya:

<?php
// Indexed array
$buah = ["apel", "jeruk", "mangga"];

// Associative array
$user = ["nama" => "Budi", "umur" => 25];

// Multidimensional
$matrix = [[1, 2], [3, 4]];

// Campuran
$campur = [0 => "nol", "satu" => 1, 2 => true];

// Array kosong
$kosong = [];

Konversi Tipe Implisit (Type Juggling) #

PHP otomatis mengonversi tipe dalam banyak konteks. Ini disebut type juggling.

Konversi ke String #

<?php
$angka = 42;
echo "Angka: " . $angka;  // "Angka: 42"

$bool = true;
echo "Aktif: " . $bool;   // "Aktif: 1" (true → "1")
$bool = false;
echo "Aktif: " . $bool;   // "Aktif: " (false → "")

$null = null;
echo "Nilai: " . $null;   // "Nilai: "

$array = [1, 2, 3];
echo "Array: " . $array;  // "Array: Array" + warning

Konversi ke Integer #

<?php
var_dump(10 + "5");       // int(15)
var_dump(10 + "5.5");     // float(15.5)
var_dump(10 + "abc");     // TypeError (PHP 8) / int(10) + warning (PHP 7)
var_dump(10 + "5abc");    // int(15) + warning (PHP 7) / TypeError (PHP 8)
var_dump(10 + true);      // int(11)
var_dump(10 + null);      // int(10)
var_dump(10 + []);        // TypeError (PHP 8)

⚠️ Peringatan: Di PHP 8, penambahan string non-numerik ke number melempar TypeError — perubahan besar dari PHP 7 yang menghasilkan warning. Ini membuat bug lebih mudah ditemukan.

Konversi ke Float #

<?php
var_dump(1.5 + "2.5");    // float(4.0)
var_dump("3.14" * 2);     // float(6.28)

Konversi ke Boolean #

<?php
if ("Hello") { }       // true
if ("") { }            // false
if ("0") { }           // false (!!)
if (0) { }             // false
if ([]) { }            // false
if ([0]) { }           // true

Konversi ke Null #

<?php
var_dump((null) "Hello");  // Syntax error — tidak valid
// null hanya bisa di-assign langsung

Konversi Tipe Eksplisit (Casting) #

Casting dengan (tipe) #

<?php
$nilai = "42";

var_dump((int) $nilai);     // int(42)
var_dump((float) $nilai);   // float(42.0)
var_dump((string) 42);      // string(2) "42"
var_dump((bool) $nilai);    // bool(true)
var_dump((array) $nilai);   // array(1) { [0]=> string(2) "42" }
var_dump((object) $nilai);  // object(stdClass)

Tipe Casting yang Tersedia #

Cast Kegunaan
(int) / (integer) Integer
(float) / (double) / (real) Float
(string) String
(bool) / (boolean) Boolean
(array) Array
(object) Object
(unset) NULL (deprecated di PHP 8)

Fungsi Konversi #

<?php
$nilai = "42";

var_dump(intval($nilai));       // int(42)
var_dump(floatval($nilai));     // float(42.0)
var_dump(strval(42));           // string(2) "42"
var_dump(boolval("0"));         // bool(false)

// settype() — mengubah tipe variabel in-place
$angka = "42";
settype($angka, "integer");
var_dump($angka);  // int(42)

Contoh Casting #

<?php
// String ke integer
$str = "42abc";
var_dump((int) $str);      // int(42) — berhenti di non-digit
var_dump(intval("abc"));   // int(0)

// String ke float
var_dump((float) "3.14abc"); // float(3.14)

// Float ke integer (truncate)
var_dump((int) 3.99);      // int(3) — truncate, bukan round!
var_dump(round(3.99));     // float(4.0)
var_dump(ceil(3.01));      // float(4.0)
var_dump(floor(3.99));     // float(3.0)

// Integer ke string
$num = 42;
var_dump((string) $num);   // string(2) "42"

// Array ke string (hati-hati!)
$arr = [1, 2, 3];
var_dump((string) $arr);   // "Array" + warning

// Boolean ke integer
var_dump((int) true);      // int(1)
var_dump((int) false);     // int(0)

Casting Array #

<?php
// Scalar ke array
var_dump((array) "Hello");
// array(1) { [0]=> string(5) "Hello" }

var_dump((array) 42);
// array(1) { [0]=> int(42) }

var_dump((array) null);
// array(0) {}

// Object ke array
class User {
    public $nama = "Budi";
    public $umur = 25;
}
$user = new User();
var_dump((array) $user);
// array(2) { ["nama"]=> string(4) "Budi" ["umur"]=> int(25) }

// Array ke object
$arr = ["nama" => "Budi", "umur" => 25];
$obj = (object) $arr;
echo $obj->nama;  // "Budi"

Perbandingan Longgar vs Ketat #

Perbedaan antara == dan === adalah sumber bug paling umum di PHP.

== (Longgar) — Konversi Tipe #

<?php
var_dump(0 == "");        // bool(true)  (!!)
var_dump(0 == "0");       // bool(true)
var_dump("" == "0");      // bool(false)
var_dump(1 == "1");       // bool(true)
var_dump(1 == "1.0");     // bool(true)
var_dump("abc" == 0);     // bool(false) di PHP 8 (sebelumnya true!)
var_dump(null == false);  // bool(true)
var_dump([] == false);    // bool(true)
var_dump("1" == "01");    // bool(true)
var_dump("10" == "1e1");  // bool(true)
var_dump(100 == "1e2");   // bool(true)

=== (Ketat) — Tanpa Konversi #

<?php
var_dump(0 === "");       // bool(false)
var_dump(0 === "0");      // bool(false)
var_dump(1 === "1");      // bool(false)
var_dump(1 === 1.0);      // bool(false) — int vs float
var_dump(null === false); // bool(false)
var_dump([] === false);   // bool(false)

Tabel Perbandingan #

Ekspresi == ===
0 == "" true false
0 == "0" true false
1 == "1" true false
1 == 1.0 true false
null == false true false
[] == false true false
"abc" == 0 false (PHP 8) false

Rekomendasi: Selalu gunakan === dan !== kecuali Anda benar-benar memahami konsekuensi konversi tipe.

in_array() dan array_search() — Mode Ketat #

<?php
$arr = [0, 1, 2, 3];

// ❌ Longgar — "abc" dianggap sama dengan 0
var_dump(in_array("abc", $arr));       // bool(true) di PHP 7, false di PHP 8

// ✅ Ketat — gunakan parameter ketiga
var_dump(in_array("abc", $arr, true)); // bool(false)

var_dump(array_search("1", $arr));        // int(1) — longgar
var_dump(array_search("1", $arr, true));  // bool(false) — ketat

Tips: Selalu berikan true sebagai parameter ketiga pada in_array() dan array_search().

Fungsi Konversi Berguna #

is_numeric() #

Mengecek apakah nilai adalah angka atau string numerik.

<?php
var_dump(is_numeric(42));       // bool(true)
var_dump(is_numeric("42"));     // bool(true)
var_dump(is_numeric("42.5"));   // bool(true)
var_dump(is_numeric("0x1A"));   // bool(false) sejak PHP 7
var_dump(is_numeric("abc"));    // bool(false)
var_dump(is_numeric("42abc"));  // bool(false)
var_dump(is_numeric(""));       // bool(false)
var_dump(is_numeric(null));     // bool(false)

ctype_* Functions #

<?php
var_dump(ctype_digit("12345"));    // bool(true)
var_dump(ctype_digit("123a"));     // bool(false)
var_dump(ctype_alpha("Hello"));    // bool(true)
var_dump(ctype_alnum("Hello123")); // bool(true)
var_dump(ctype_upper("HELLO"));    // bool(true)
var_dump(ctype_lower("hello"));    // bool(true)

filter_var() #

Validasi dan sanitasi input — sangat berguna untuk data dari user.

<?php
// Validasi integer
var_dump(filter_var("42", FILTER_VALIDATE_INT));     // int(42)
var_dump(filter_var("abc", FILTER_VALIDATE_INT));    // bool(false)
var_dump(filter_var("0", FILTER_VALIDATE_INT));      // int(0)
var_dump(filter_var("42", FILTER_VALIDATE_INT, [
    "options" => ["min_range" => 1, "max_range" => 100]
])); // bool(false) — di luar rentang

// Validasi email
var_dump(filter_var("budi@example.com", FILTER_VALIDATE_EMAIL)); // string
var_dump(filter_var("bukan-email", FILTER_VALIDATE_EMAIL));      // bool(false)

// Validasi URL
var_dump(filter_var("https://example.com", FILTER_VALIDATE_URL)); // string

// Validasi boolean
var_dump(filter_var("true", FILTER_VALIDATE_BOOLEAN));  // bool(true)
var_dump(filter_var("false", FILTER_VALIDATE_BOOLEAN)); // bool(false)
var_dump(filter_var("1", FILTER_VALIDATE_BOOLEAN));     // bool(true)
var_dump(filter_var("0", FILTER_VALIDATE_BOOLEAN));     // bool(false)

// Sanitasi string (hapus karakter berbahaya)
var_dump(filter_var("<script>alert('xss')</script>", FILTER_SANITIZE_SPECIAL_CHARS));
// "&lt;script&gt;alert(&#039;xss&#039;)&lt;/script&gt;"

// Sanitasi email
var_dump(filter_var("budi@example.com<script>", FILTER_SANITIZE_EMAIL));
// "budi@example.comscript"

settype() — Mengubah Tipe In-Place #

<?php
$nilai = "42";
settype($nilai, "integer");
var_dump($nilai);  // int(42)

$nilai = 42;
settype($nilai, "string");
var_dump($nilai);  // string(2) "42"

$nilai = "3.14";
settype($nilai, "float");
var_dump($nilai);  // float(3.14)

// Tipe yang didukung: "int", "integer", "float", "double", "string", "bool", "boolean", "array", "object", "null"

Contoh Praktis: Validasi Input Form #

Mari gabungkan konsep tipe data dan konversi untuk validasi input:

<?php
function validasiForm(array $input): array {
    $error = [];

    // Nama — string, minimal 3 karakter
    $nama = trim($input['nama'] ?? '');
    if ($nama === '') {
        $error['nama'] = 'Nama wajib diisi';
    } elseif (mb_strlen($nama) < 3) {
        $error['nama'] = 'Nama minimal 3 karakter';
    }

    // Umur — integer, 17-100
    $umurRaw = $input['umur'] ?? '';
    $umur = filter_var($umurRaw, FILTER_VALIDATE_INT, [
        'options' => ['min_range' => 17, 'max_range' => 100]
    ]);
    if ($umur === false) {
        $error['umur'] = 'Umur harus bilangan bulat antara 17 dan 100';
    }

    // Email — valid
    $email = filter_var($input['email'] ?? '', FILTER_VALIDATE_EMAIL);
    if ($email === false) {
        $error['email'] = 'Email tidak valid';
    }

    // Harga — float positif
    $hargaRaw = $input['harga'] ?? '';
    $harga = filter_var($hargaRaw, FILTER_VALIDATE_FLOAT);
    if ($harga === false || $harga < 0) {
        $error['harga'] = 'Harga harus angka positif';
    }

    // Aktif — boolean
    $aktif = filter_var($input['aktif'] ?? false, FILTER_VALIDATE_BOOLEAN);

    return [
        'valid' => empty($error),
        'error' => $error,
        'data' => empty($error) ? [
            'nama' => $nama,
            'umur' => $umur,
            'email' => $email,
            'harga' => $harga,
            'aktif' => $aktif,
        ] : null,
    ];
}

// Uji
$hasil = validasiForm([
    'nama' => 'Budi Santoso',
    'umur' => '25',
    'email' => 'budi@example.com',
    'harga' => '150000.50',
    'aktif' => 'true',
]);

var_dump($hasil);
// [
//   "valid" => true,
//   "error" => [],
//   "data" => [
//     "nama" => "Budi Santoso",
//     "umur" => 25,
//     "email" => "budi@example.com",
//     "harga" => 150000.5,
//     "aktif" => true,
//   ]
// ]

$hasil2 = validasiForm([
    'nama' => 'B',
    'umur' => '15',
    'email' => 'bukan-email',
    'harga' => '-100',
]);

var_dump($hasil2['error']);
// [
//   "nama" => "Nama minimal 3 karakter",
//   "umur" => "Umur harus bilangan bulat antara 17 dan 100",
//   "email" => "Email tidak valid",
//   "harga" => "Harga harus angka positif",
// ]

Ringkasan #

Tipe Cek Cast
string is_string() (string)
int is_int() (int)
float is_float() (float)
bool is_bool() (bool)
null is_null() —
array is_array() (array)
object is_object() (object)
numeric is_numeric() —

Falsy values di PHP: false, 0, 0.0, "", "0", [], null.

Poin penting:

  • PHP loosely typed — konversi tipe terjadi otomatis.
  • "0" adalah falsy di PHP (beda dengan JavaScript).
  • Selalu gunakan === dan !== untuk perbandingan.
  • in_array() dan array_search() — selalu berikan true sebagai parameter ketiga.
  • Jangan gunakan float untuk uang — gunakan integer atau BCMath.
  • (int) 3.99 → 3 (truncate, bukan round).
  • PHP 8 melempar TypeError untuk operasi string non-numerik — lebih aman dari PHP 7.
  • Gunakan filter_var() untuk validasi input dari user.
  • Gunakan mb_* functions untuk string Unicode.
  • isset() false untuk null; is_null() true untuk null.
