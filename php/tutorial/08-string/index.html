Pendahuluan #

String adalah urutan karakter — tipe data yang paling sering diolah dalam aplikasi web. Mulai dari menampilkan nama user, memformat harga, memvalidasi input, hingga memproses teks dari database, semuanya melibatkan string.

PHP menyediakan puluhan fungsi string bawaan yang membuat manipulasi teks menjadi mudah. Artikel ini membahas fungsi-fungsi yang paling sering digunakan, cara formatting, heredoc/nowdoc, multibyte string untuk Unicode, serta regex dasar.

Asumsi: Anda sudah memahami variabel, tipe data, fungsi, dan array dari artikel sebelumnya.

Membuat String #

Single Quote, Double Quote, dan Heredoc #

<?php
$single = 'Hello';
$double = "Hello";
$heredoc = <<<EOT
Hello, World!
EOT;
$nowdoc = <<<'EOT'
Hello, World!
EOT;

Perbedaan:

Aspek Single Quote '...' Double Quote "..." Heredoc <<<EOT Nowdoc <<<'EOT'
Interpolasi variabel Tidak Ya Ya Tidak
Escape \n, \t Tidak Ya Ya Tidak
Multi-baris Tidak Tidak (kecuali \n) Ya Ya
Performa Paling cepat Sedikit lebih lambat Sedikit lebih lambat Paling cepat untuk multi-baris

Interpolasi Variabel #

Double quote:

<?php
$nama = "Budi";
$umur = 25;

echo "Halo, $nama! Umur Anda $umur tahun.";
// "Halo, Budi! Umur Anda 25 tahun."

// Kurung kurawal untuk ekspresi kompleks
echo "Halo, {$nama}!";
echo "Total: {$harga * $jumlah}";

Heredoc:

<?php
$nama = "Budi";
$umur = 25;

$teks = <<<EOT
Halo, $nama!
Umur Anda $umur tahun.
EOT;

echo $teks;
// Halo, Budi!
// Umur Anda 25 tahun.

Tips: Gunakan single quote untuk string statis (performa lebih baik), double quote atau heredoc jika butuh interpolasi, dan nowdoc untuk string multi-baris tanpa interpolasi (misalnya SQL atau kode).

Escape Character #

Escape Arti
\n Baris baru
\t Tab
\r Carriage return
\\ Backslash
\' Single quote (dalam single quote)
\" Double quote (dalam double quote)
\$ Dolar literal (dalam double quote)
\u{XXXX} Unicode (PHP 7+) 
<?php
echo "Baris 1\nBaris 2";
echo "Tab\tDi sini";
echo "Dia berkata: \"Halo!\"";
echo 'It\'s okay';
echo "Harga: \$100";
echo "\u{1F600}"; // 😀

Fungsi String Dasar #

Panjang String #

<?php
$teks = "Hello World";

echo strlen($teks);       // 11 (byte)
echo mb_strlen($teks);    // 11 (karakter)

$unicode = "Halo, 世界!";
echo strlen($unicode);    // 13 (byte)
echo mb_strlen($unicode); // 10 (karakter)

Tips: Gunakan mb_strlen() untuk string yang mungkin mengandung karakter Unicode (emoji, huruf non-Latin).

Mengubah Case #

<?php
$teks = "Hello World";

echo strtolower($teks);   // "hello world"
echo strtoupper($teks);   // "HELLO WORLD"
echo ucfirst("hello");    // "Hello"
echo lcfirst("Hello");    // "hello"
echo ucwords("hello world"); // "Hello World"

// Multibyte
echo mb_strtolower("HALO DUNIA"); // "halo dunia"
echo mb_strtoupper("halo dunia"); // "HALO DUNIA"

Trim (Hapus Spasi) #

<?php
$teks = "  Hello World  ";

echo trim($teks);       // "Hello World"
echo ltrim($teks);      // "Hello World  " (kiri)
echo rtrim($teks);      // "  Hello World" (kanan)

// Trim karakter tertentu
$kode = "###Hello###";
echo trim($kode, "#");  // "Hello"

$csv = "apel,jeruk,";
echo rtrim($csv, ",");  // "apel,jeruk"

Mencari Substring #

<?php
$teks = "Hello World";

echo strpos($teks, "World");    // 6
echo strpos($teks, "world");    // false (case-sensitive)
echo stripos($teks, "world");   // 6 (case-insensitive)

echo strrpos($teks, "o");       // 7 (posisi terakhir)

// PHP 8+
var_dump(str_contains($teks, "World"));    // bool(true)
var_dump(str_starts_with($teks, "Hello")); // bool(true)
var_dump(str_ends_with($teks, "World"));   // bool(true)

Peringatan: strpos() mengembalikan 0 jika substring ada di awal string. Selalu gunakan !== false untuk mengecek keberadaan, bukan != false atau if (strpos(...)).

<?php
$teks = "Hello World";

// ❌ Salah — 0 dianggap falsy
if (strpos($teks, "Hello")) {
    echo "Tidak akan jalan";
}

// ✅ Benar
if (strpos($teks, "Hello") !== false) {
    echo "Ditemukan di awal";
}

Mengambil Substring #

<?php
$teks = "Hello World";

echo substr($teks, 0, 5);   // "Hello"
echo substr($teks, 6);      // "World"
echo substr($teks, -5);     // "World" (dari akhir)
echo substr($teks, 0, -6);  // "Hello" (buang 6 karakter terakhir)

// Multibyte
echo mb_substr("Halo, 世界!", 0, 5); // "Halo,"

Mengganti String #

<?php
$teks = "Hello World";

echo str_replace("World", "PHP", $teks);   // "Hello PHP"
echo str_ireplace("world", "PHP", $teks);  // "Hello PHP" (case-insensitive)

// Dengan array
$cari = ["Hello", "World"];
$ganti = ["Halo", "Dunia"];
echo str_replace($cari, $ganti, $teks);    // "Halo Dunia"

// Hitung jumlah penggantian
$jumlah = 0;
str_replace("o", "0", $teks, $jumlah);
echo $jumlah; // 2

Catatan: str_replace() mengganti semua kemunculan. Untuk mengganti hanya sekali, gunakan preg_replace() dengan limit, atau fungsi khusus.

Membalik String #

<?php
echo strrev("Hello"); // "olleH"

Mengulang String #

<?php
echo str_repeat("ab", 3);  // "ababab"
echo str_repeat("-", 20);  // "--------------------"

Padding #

<?php
echo str_pad("5", 3, "0", STR_PAD_LEFT);   // "005"
echo str_pad("5", 3, "0", STR_PAD_RIGHT);  // "500"
echo str_pad("5", 3, "0", STR_PAD_BOTH);   // "050"

echo str_pad("Hello", 10, "*", STR_PAD_BOTH); // "**Hello***"

Memecah dan Menggabung String #

explode() — String ke Array #

<?php
$csv = "apel,jeruk,mangga";
$buah = explode(",", $csv);
print_r($buah); // ["apel", "jeruk", "mangga"]

// Dengan limit
$bagian = explode(",", $csv, 2);
print_r($bagian); // ["apel", "jeruk,mangga"]

// Pecah per karakter
$chars = str_split("Hello");
print_r($chars); // ["H", "e", "l", "l", "o"]

// Pecah per 2 karakter
$chunks = str_split("HelloWorld", 2);
print_r($chunks); // ["He", "ll", "oW", "or", "ld"]

implode() — Array ke String #

<?php
$buah = ["apel", "jeruk", "mangga"];

echo implode(", ", $buah);  // "apel, jeruk, mangga"
echo implode(" - ", $buah); // "apel - jeruk - mangga"
echo implode("", $buah);    // "apeljerukmangga"

// Alias: join()
echo join(", ", $buah);     // "apel, jeruk, mangga"

preg_split() — Pecah dengan Regex #

<?php
$teks = "apel, jeruk; mangga|pisang";
$buah = preg_split("/[,;|]\s*/", $teks);
print_r($buah); // ["apel", "jeruk", "mangga", "pisang"]

Formatting String #

sprintf() dan printf() #

sprintf() mengembalikan string terformat, printf() langsung mencetak.

<?php
$nama = "Budi";
$umur = 25;
$harga = 150000.5;

// sprintf — mengembalikan string
$teks = sprintf("Halo, %s! Umur Anda %d tahun.", $nama, $umur);
echo $teks; // "Halo, Budi! Umur Anda 25 tahun."

// printf — langsung mencetak
printf("Halo, %s! Umur Anda %d tahun.\n", $nama, $umur);

// Format harga
printf("Harga: Rp%.2f\n", $harga); // "Harga: Rp150000.50"

// Padding
printf("|%10s|\n", "Hello");  // "|     Hello|"
printf("|%-10s|\n", "Hello"); // "|Hello     |"
printf("|%010d|\n", 42);      // "|0000000042|"

Format specifier umum:

Specifier Arti
%s String
%d Integer
%f Float
%.2f Float 2 desimal
%x Heksadesimal
%b Biner
%o Oktal
%e Notasi ilmiah
%% Karakter % literal
%10s String, lebar 10 (rata kanan)
%-10s String, lebar 10 (rata kiri)
%010d Integer, lebar 10, padding nol

number_format() — Format Angka #

<?php
$angka = 1500000.567;

echo number_format($angka);                    // "1,500,001" (dibulatkan)
echo number_format($angka, 2);                 // "1,500,000.57"
echo number_format($angka, 2, ",", ".");       // "1.500.000,57" (format Indonesia)
echo number_format($angka, 0, ",", ".");       // "1.500.001"

// Format Rupiah
echo "Rp" . number_format(1500000, 0, ",", "."); // "Rp1.500.000"

nl2br() — Newline ke <br> #

<?php
$teks = "Baris 1\nBaris 2\nBaris 3";
echo nl2br($teks);
// "Baris 1<br />\nBaris 2<br />\nBaris 3"

Peringatan: nl2br() tidak meng-escape HTML. Selalu gabungkan dengan htmlspecialchars() untuk output ke browser.

wordwrap() — Bungkus Teks #

<?php
$teks = "Ini adalah teks yang sangat panjang dan perlu dibungkus.";
echo wordwrap($teks, 20, "\n", true);

htmlspecialchars() — Escape HTML #

Wajib digunakan saat menampilkan input user ke HTML — mencegah XSS.

<?php
$input = '<script>alert("XSS")</script>';
echo htmlspecialchars($input);
// "&lt;script&gt;alert(&quot;XSS&quot;)&lt;/script&gt;"

// Dengan ENT_QUOTES (escape single dan double quote)
echo htmlspecialchars($input, ENT_QUOTES, "UTF-8");

Tips: Selalu gunakan htmlspecialchars($string, ENT_QUOTES, "UTF-8") saat menampilkan data dari user ke HTML. Ini adalah pertahanan utama terhadap XSS.

strip_tags() — Hapus Tag HTML #

<?php
$html = "<p>Hello <strong>World</strong></p>";
echo strip_tags($html); // "Hello World"

// Izinkan tag tertentu
echo strip_tags($html, "<strong>"); // "Hello <strong>World</strong>"

Catatan: strip_tags() bukan pengganti htmlspecialchars(). Gunakan htmlspecialchars() untuk output, strip_tags() hanya jika memang perlu menghapus tag.

Multibyte String (Unicode) #

Fungsi strlen(), substr(), strpos() bekerja pada byte, bukan karakter. Untuk string Unicode (emoji, huruf non-Latin), gunakan mb_*.

<?php
$teks = "Halo, 世界! 😀";

// Byte vs karakter
echo strlen($teks);       // 19 (byte)
echo mb_strlen($teks);    // 11 (karakter)

// Substring
echo substr($teks, 0, 5);    // "Halo," (mungkin rusak untuk Unicode)
echo mb_substr($teks, 0, 5); // "Halo," (aman)

// Posisi
echo mb_strpos($teks, "世界"); // 6

Tips: Jika aplikasi Anda menangani teks non-ASCII, selalu gunakan mb_* functions dan set default_charset = "UTF-8" di php.ini.

Fungsi mb_* umum:

Fungsi Byte Fungsi Multibyte
strlen() mb_strlen()
substr() mb_substr()
strpos() mb_strpos()
strtolower() mb_strtolower()
strtoupper() mb_strtoupper()
str_split() mb_str_split() (PHP 7.4+)

Regex Dasar #

PHP mendukung PCRE (Perl Compatible Regular Expressions) melalui fungsi preg_*.

preg_match() — Cek Pola #

Mengembalikan 1 jika cocok, 0 jika tidak.

<?php
$teks = "Halo, Budi!";

// Cek apakah mengandung "Budi"
if (preg_match("/Budi/", $teks)) {
    echo "Ditemukan";
}

// Dengan capture group
preg_match("/Halo, (\w+)!/", $teks, $matches);
print_r($matches);
// [0 => "Halo, Budi!", 1 => "Budi"]

preg_match_all() — Cari Semua Kecocokan #

<?php
$teks = "Email: budi@example.com, siti@example.org";

preg_match_all("/[\w.]+@[\w.]+/", $teks, $matches);
print_r($matches[0]);
// ["budi@example.com", "siti@example.org"]

preg_replace() — Ganti dengan Pola #

<?php
$teks = "Halo, Budi! Halo, Siti!";

echo preg_replace("/Halo/", "Hi", $teks);
// "Hi, Budi! Hi, Siti!"

// Dengan capture group
echo preg_replace("/(\w+)@(\w+)\.com/", "$1 [at] $2", "budi@example.com");
// "budi [at] example"

preg_split() — Pecah dengan Pola #

<?php
$teks = "apel, jeruk; mangga|pisang";
$buah = preg_split("/[,;|]\s*/", $teks);
print_r($buah); // ["apel", "jeruk", "mangga", "pisang"]

Pola Regex Umum #

Pola Arti
. Karakter apa pun (kecuali newline)
\d Digit (0-9)
\D Bukan digit
\w Word character (huruf, angka, underscore)
\W Bukan word character
\s Whitespace (spasi, tab, newline)
\S Bukan whitespace
^ Awal string
$ Akhir string
* 0 atau lebih
+ 1 atau lebih
? 0 atau 1
{n} Tepat n kali
{n,m} Antara n dan m kali
[abc] Salah satu dari a, b, c
[^abc] Bukan a, b, c
(abc) Capture group
(?:abc) Non-capture group
a|b a atau b
\b Word boundary

Contoh Pola Umum #

<?php
// Email
$email = "budi@example.com";
var_dump(preg_match("/^[\w.+-]+@[\w-]+\.[\w.]+$/", $email)); // 1

// Nomor telepon Indonesia
$telepon = "081234567890";
var_dump(preg_match("/^08\d{8,11}$/", $telepon)); // 1

// URL
$url = "https://example.com/path?query=1";
var_dump(preg_match("/^https?:\/\/[\w.-]+/", $url)); // 1

// Username (huruf, angka, underscore, 3-20 karakter)
$username = "budi_123";
var_dump(preg_match("/^\w{3,20}$/", $username)); // 1

// Slug (huruf kecil, angka, dash)
$slug = "hello-world-123";
var_dump(preg_match("/^[a-z0-9-]+$/", $slug)); // 1

Flag Regex #

<?php
$teks = "Hello World";

// i — case-insensitive
preg_match("/hello/i", $teks); // 1

// m — multi-line (^ dan $ per baris)
preg_match("/^World$/m", "Hello\nWorld"); // 1

// s — dotall (. cocok dengan newline)
preg_match("/Hello.World/s", "Hello\nWorld"); // 1

// u — UTF-8 (untuk Unicode)
preg_match("/世界/u", "Halo, 世界!"); // 1

preg_quote() — Escape Karakter Regex #

<?php
$input = "Harga: Rp100.000 (diskon)";
$pola = "/" . preg_quote($input, "/") . "/";
// Pola aman untuk mencari $input literal

Tips: Selalu gunakan preg_quote() saat memasukkan input user ke dalam pola regex — mencegah karakter khusus merusak pola.

Error Handling Regex #

<?php
$pola = "/[a-z/"; // pola tidak valid

if (preg_match($pola, "test") === false) {
    echo "Pola regex tidak valid: " . preg_last_error_msg();
}

Contoh Praktis #

1. Format Nama #

<?php
function formatNama(string $nama): string {
    $nama = trim($nama);
    $nama = preg_replace("/\s+/", " ", $nama); // rapikan spasi
    return ucwords(mb_strtolower($nama));
}

echo formatNama("  budi   santoso  "); // "Budi Santoso"
echo formatNama("SITI AMINAH");       // "Siti Aminah"

2. Slug dari Judul #

<?php
function buatSlug(string $judul): string {
    $slug = mb_strtolower($judul);
    $slug = preg_replace("/[^\w\s-]/u", "", $slug); // hapus karakter non-word
    $slug = preg_replace("/[\s_]+/", "-", $slug);    // spasi/underscore → dash
    $slug = trim($slug, "-");                         // trim dash di ujung
    return $slug;
}

echo buatSlug("Panduan Lengkap PHP untuk Pemula!");
// "panduan-lengkap-php-untuk-pemula"

3. Potong Teks dengan Ellipsis #

<?php
function potongTeks(string $teks, int $panjang = 100): string {
    $teks = strip_tags($teks);
    if (mb_strlen($teks) <= $panjang) {
        return $teks;
    }
    return mb_substr($teks, 0, $panjang) . "...";
}

echo potongTeks("Ini adalah teks yang sangat panjang dan perlu dipotong.", 20);
// "Ini adalah teks ya..."

4. Validasi Email #

<?php
function validasiEmail(string $email): bool {
    return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
}

var_dump(validasiEmail("budi@example.com")); // bool(true)
var_dump(validasiEmail("bukan-email"));      // bool(false)

Tips: Untuk validasi email, gunakan filter_var() dengan FILTER_VALIDATE_EMAIL — lebih akurat daripada regex manual.

5. Ekstrak Data dari String #

<?php
$log = "[2022-12-01 10:30:45] INFO: User budi@example.com login";

// Ekstrak tanggal, level, email
preg_match("/\[([\d-]+) ([\d:]+)\] (\w+): .+ ([\w.]+@[\w.]+)/", $log, $matches);
print_r($matches);
// [
//   0 => "[2022-12-01 10:30:45] INFO: User budi@example.com",
//   1 => "2022-12-01",
//   2 => "10:30:45",
//   3 => "INFO",
//   4 => "budi@example.com"
// ]

// Named capture group
preg_match("/\[(?<tanggal>[\d-]+) (?<waktu>[\d:]+)\] (?<level>\w+)/", $log, $m);
echo $m["tanggal"]; // "2022-12-01"
echo $m["level"];   // "INFO"

6. Format Rupiah #

<?php
function formatRupiah(float $angka): string {
    return "Rp" . number_format($angka, 0, ",", ".");
}

echo formatRupiah(1500000);    // "Rp1.500.000"
echo formatRupiah(1500000.75); // "Rp1.500.001"

7. Hitung Kata #

<?php
function hitungKata(string $teks): int {
    $teks = trim($teks);
    if ($teks === "") return 0;
    return count(preg_split("/\s+/", $teks));
}

echo hitungKata("Halo, dunia! Ini adalah kalimat."); // 5

Tips dan Best Practice #

  1. Gunakan mb_* functions untuk string Unicode — strlen() dan substr() bekerja pada byte, bukan karakter.

  2. Selalu htmlspecialchars() saat menampilkan input user ke HTML — mencegah XSS.

<?php
// SELALU
echo htmlspecialchars($userInput, ENT_QUOTES, "UTF-8");

  1. Gunakan !== false saat mengecek strpos() — 0 adalah posisi valid.

  2. Gunakan single quote untuk string statis — performa lebih baik.

  3. Gunakan preg_quote() saat memasukkan input user ke pola regex.

  4. Gunakan filter_var() untuk validasi email/URL — lebih akurat daripada regex manual.

  5. Gunakan str_contains(), str_starts_with(), str_ends_with() (PHP 8+) daripada strpos() — lebih mudah dibaca.

  6. Hindari regex untuk tugas sederhana — str_replace() atau explode() seringkali lebih cepat dan mudah dibaca.

  7. Gunakan sprintf() untuk formatting kompleks — lebih rapi daripada concatenation.

  8. Trim input user sebelum diproses — mencegah spasi tak sengaja.

  9. Gunakan nl2br() dengan hati-hati — tidak meng-escape HTML. Gabungkan dengan htmlspecialchars().

  10. Untuk string multi-baris, gunakan heredoc (dengan interpolasi) atau nowdoc (tanpa interpolasi).
