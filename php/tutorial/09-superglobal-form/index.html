Pendahuluan #

Aplikasi web tidak lepas dari input dari user — mengisi form, mengirim data, mengunggah file. PHP menyediakan superglobal — variabel bawaan yang bisa diakses dari mana saja, termasuk di dalam fungsi, tanpa perlu global.

Superglobal utama untuk form handling:

  • $_GET — data dari query string (URL).
  • $_POST — data dari form method POST.
  • $_REQUEST — gabungan GET, POST, dan COOKIE.
  • $_SERVER — informasi server dan request.
  • $_FILES — file yang diunggah.

Artikel ini membahas cara memproses form dengan aman: validasi, sanitasi, dan upload file.

Asumsi: Anda sudah memahami variabel, array, string, dan fungsi dari artikel sebelumnya.

Apa Itu Superglobal? #

Superglobal adalah array bawaan PHP yang tersedia di semua scope — global, fungsi, method. Namanya diawali $_ dan ditulis huruf besar.

Superglobal Isi
$_GET Data dari query string
$_POST Data dari form method POST
$_REQUEST Gabungan GET, POST, COOKIE
$_SERVER Info server dan request
$_FILES File yang diunggah
$_SESSION Data session (dibahas artikel terpisah)
$_COOKIE Data cookie (dibahas artikel terpisah)
$_ENV Environment variables
$GLOBALS Semua variabel global 
<?php
// Bisa diakses di dalam fungsi tanpa `global`
function tampilkanNama() {
    echo $_GET["nama"] ?? "Anonim";
}

tampilkanNama();

Peringatan: Jangan pernah mempercayai data superglobal langsung. Selalu validasi dan sanitasi sebelum digunakan.

$_GET — Data dari Query String #

Data dikirim melalui URL setelah tanda ?.

https://example.com/produk.php?kategori=elektronik&page=2

<?php
// URL: produk.php?kategori=elektronik&page=2
$kategori = $_GET["kategori"] ?? "";
$page = $_GET["page"] ?? 1;

echo "Kategori: $kategori"; // "elektronik"
echo "Halaman: $page";       // "2"

Karakteristik $_GET #

  • Data terlihat di URL — jangan kirim data sensitif (password, token).
  • Panjang terbatas (sekitar 2000 karakter, tergantung browser dan server).
  • Bisa di-bookmark dan di-share.
  • Cocok untuk pencarian, filter, pagination.
  • Idempotent — request GET seharusnya tidak mengubah data di server.

Form dengan Method GET #

<form action="cari.php" method="get">
    <input type="text" name="q" placeholder="Cari produk...">
    <button type="submit">Cari</button>
</form>

Saat di-submit, URL menjadi:

cari.php?q=laptop

<?php
// cari.php
$keyword = $_GET["q"] ?? "";
if ($keyword !== "") {
    echo "Mencari: " . htmlspecialchars($keyword);
}

Query String dengan Array #

<form method="get">
    <input type="checkbox" name="kategori[]" value="elektronik"> Elektronik
    <input type="checkbox" name="kategori[]" value="fashion"> Fashion
    <button type="submit">Filter</button>
</form>

<?php
// URL: filter.php?kategori[]=elektronik&kategori[]=fashion
$kategori = $_GET["kategori"] ?? [];
print_r($kategori);
// ["elektronik", "fashion"]

Catatan: Nama input dengan [] di akhir membuat PHP mengumpulkan nilai menjadi array.

Membangun Query String #

<?php
$params = [
    "kategori" => "elektronik",
    "page" => 2,
    "limit" => 10,
];

$query = http_build_query($params);
echo $query;
// "kategori=elektronik&page=2&limit=10"

// Gunakan di URL
$url = "produk.php?" . $query;
echo $url;
// "produk.php?kategori=elektronik&page=2&limit=10"

Tips: Gunakan http_build_query() untuk membangun query string — otomatis meng-encode karakter khusus.

$_POST — Data dari Form POST #

Data dikirim melalui body request, tidak terlihat di URL.

<form action="proses.php" method="post">
    <input type="text" name="nama" placeholder="Nama">
    <input type="email" name="email" placeholder="Email">
    <input type="password" name="password" placeholder="Password">
    <button type="submit">Daftar</button>
</form>

<?php
// proses.php
$nama = $_POST["nama"] ?? "";
$email = $_POST["email"] ?? "";
$password = $_POST["password"] ?? "";

echo "Nama: " . htmlspecialchars($nama);
echo "Email: " . htmlspecialchars($email);
// JANGAN tampilkan password!

Karakteristik $_POST #

  • Data tidak terlihat di URL — cocok untuk data sensitif.
  • Tidak ada batasan panjang yang ketat (tergantung post_max_size).
  • Tidak idempotent — request POST seharusnya mengubah data di server.
  • Cocok untuk login, registrasi, create/update data.
  • Tidak bisa di-bookmark.

Cek Method Request #

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // proses form
    $nama = $_POST["nama"] ?? "";
    // ...
}

Tips: Selalu cek $_SERVER["REQUEST_METHOD"] sebelum memproses form — mencegah eksekusi kode saat halaman diakses langsung via GET.

Form dengan File Upload #

Form yang mengunggah file wajib menggunakan enctype="multipart/form-data":

<form action="upload.php" method="post" enctype="multipart/form-data">
    <input type="file" name="foto">
    <button type="submit">Upload</button>
</form>

Tanpa enctype, file tidak akan terkirim.

$_REQUEST — Gabungan GET, POST, COOKIE #

$_REQUEST menggabungkan $_GET, $_POST, dan $_COOKIE. Urutan prioritas ditentukan oleh request_order di php.ini (default: GP — GET lalu POST).

<?php
// Bisa dari GET atau POST
$nama = $_REQUEST["nama"] ?? "";

⚠️ Peringatan: Hindari $_REQUEST — sulit diprediksi dan bisa menjadi celah keamanan. Gunakan $_GET atau $_POST secara eksplisit sesuai kebutuhan.

$_SERVER — Informasi Server dan Request #

Berisi informasi tentang server dan request yang sedang diproses.

<?php
// Method request
echo $_SERVER["REQUEST_METHOD"]; // "GET" / "POST"

// URL dan path
echo $_SERVER["REQUEST_URI"];    // "/produk.php?page=2"
echo $_SERVER["SCRIPT_NAME"];    // "/produk.php"
echo $_SERVER["PHP_SELF"];       // "/produk.php" (hati-hati XSS!)

// Host dan port
echo $_SERVER["HTTP_HOST"];      // "example.com"
echo $_SERVER["SERVER_NAME"];    // "example.com"
echo $_SERVER["SERVER_PORT"];    // "80" / "443"

// IP client
echo $_SERVER["REMOTE_ADDR"];   // "192.168.1.10"

// User agent
echo $_SERVER["HTTP_USER_AGENT"]; // "Mozilla/5.0 ..."

// HTTPS?
$isHttps = !empty($_SERVER["HTTPS"]) && $_SERVER["HTTPS"] !== "off";

PHP_SELF dan XSS #

$_SERVER["PHP_SELF"] bisa dimanipulasi oleh penyerang melalui URL:

https://example.com/produk.php/"><script>alert('XSS')</script>

Jika digunakan langsung di form action:

<!-- ❌ RENTAN XSS -->
<form action="<?= $_SERVER['PHP_SELF'] ?>">

Solusi:

<!-- ✅ AMAN -->
<form action="<?= htmlspecialchars($_SERVER['PHP_SELF'], ENT_QUOTES, 'UTF-8') ?>">

<!-- ✅ Lebih baik: gunakan path spesifik -->
<form action="/proses.php">

Peringatan: Jangan pernah menampilkan $_SERVER["PHP_SELF"] tanpa htmlspecialchars().

Mendapatkan IP Client #

<?php
function getClientIp(): string {
    // Jika di belakang proxy, cek header X-Forwarded-For
    if (!empty($_SERVER["HTTP_X_FORWARDED_FOR"])) {
        $ips = explode(",", $_SERVER["HTTP_X_FORWARDED_FOR"]);
        return trim($ips[0]);
    }
    return $_SERVER["REMOTE_ADDR"] ?? "unknown";
}

Catatan: Header X-Forwarded-For bisa dipalsukan. Hanya percayai jika request datang dari proxy tepercaya.

$_FILES — Upload File #

Berisi informasi file yang diunggah melalui form multipart/form-data.

Struktur $_FILES #

<?php
print_r($_FILES["foto"]);
// [
//     "name" => "gambar.jpg",         // nama asli
//     "type" => "image/jpeg",         // MIME type (bisa dipalsukan!)
//     "tmp_name" => "/tmp/phpXXXX",   // lokasi sementara
//     "error" => 0,                   // kode error
//     "size" => 102400                // ukuran dalam byte
// ]

Kode Error Upload #

Kode Konstanta Arti
0 UPLOAD_ERR_OK Berhasil
1 UPLOAD_ERR_INI_SIZE Melebihi upload_max_filesize
2 UPLOAD_ERR_FORM_SIZE Melebihi MAX_FILE_SIZE di form
3 UPLOAD_ERR_PARTIAL Upload terputus
4 UPLOAD_ERR_NO_FILE Tidak ada file
6 UPLOAD_ERR_NO_TMP_DIR Folder tmp tidak ada
7 UPLOAD_ERR_CANT_WRITE Gagal menulis ke disk
8 UPLOAD_ERR_EXTENSION Diblokir oleh ekstensi PHP

Proses Upload Aman #

<?php
function uploadGambar(array $file, string $uploadDir = "uploads/"): array {
    // 1. Cek error
    if ($file["error"] !== UPLOAD_ERR_OK) {
        return ["sukses" => false, "pesan" => "Upload gagal (kode: {$file['error']})"];
    }

    // 2. Cek ukuran (maks 2MB)
    if ($file["size"] > 2 * 1024 * 1024) {
        return ["sukses" => false, "pesan" => "Ukuran maksimal 2MB"];
    }

    // 3. Cek MIME type dengan finfo (JANGAN percaya $file["type"]!)
    $finfo = new finfo(FILEINFO_MIME_TYPE);
    $mime = $finfo->file($file["tmp_name"]);
    $izinMime = ["image/jpeg", "image/png", "image/webp", "image/gif"];

    if (!in_array($mime, $izinMime, true)) {
        return ["sukses" => false, "pesan" => "Format file tidak didukung"];
    }

    // 4. Buat nama file unik — JANGAN gunakan nama asli!
    $ext = match ($mime) {
        "image/jpeg" => ".jpg",
        "image/png" => ".png",
        "image/webp" => ".webp",
        "image/gif" => ".gif",
    };
    $namaBaru = bin2hex(random_bytes(16)) . $ext;

    // 5. Pastikan folder upload ada
    if (!is_dir($uploadDir)) {
        mkdir($uploadDir, 0755, true);
    }

    // 6. Pindahkan file
    $tujuan = $uploadDir . $namaBaru;
    if (!move_uploaded_file($file["tmp_name"], $tujuan)) {
        return ["sukses" => false, "pesan" => "Gagal menyimpan file"];
    }

    return ["sukses" => true, "pesan" => "Upload berhasil", "file" => $namaBaru];
}

// Penggunaan
if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_FILES["foto"])) {
    $hasil = uploadGambar($_FILES["foto"]);
    echo $hasil["pesan"];
}

⚠️ Peringatan keamanan:

  • Jangan percaya $_FILES["type"] — MIME type dari client bisa dipalsukan. Gunakan finfo untuk memeriksa isi file.
  • Jangan gunakan nama file asli — bisa mengandung karakter berbahaya atau menimpa file lain. Generate nama unik.
  • Batasi ekstensi dan ukuran — cegah upload file berbahaya.
  • Simpan file di luar document root jika memungkinkan, atau nonaktifkan eksekusi PHP di folder upload.

Menonaktifkan Eksekusi PHP di Folder Upload #

Buat file .htaccess di folder uploads/:

# uploads/.htaccess
php_flag engine off
<FilesMatch "\.(php|phtml|php3|php4|php5|php7|phps)$">
    Deny from all
</FilesMatch>

Untuk Nginx:

location /uploads/ {
    location ~ \.php$ {
        deny all;
    }
}

Validasi dan Sanitasi Input #

Validasi memastikan data memenuhi aturan. Sanitasi membersihkan data dari karakter berbahaya.

Prinsip Dasar #

  1. Jangan pernah percaya input user — semua bisa dimanipulasi.
  2. Validasi di server — validasi di client (JavaScript) hanya untuk UX, bukan keamanan.
  3. Whitelist, bukan blacklist — tentukan apa yang diizinkan, bukan apa yang dilarang.
  4. Gunakan filter_var() untuk validasi standar (email, URL, integer).
  5. Selalu htmlspecialchars() saat output ke HTML.

Validasi dengan filter_var() #

<?php
// Integer
$umur = filter_var($_POST["umur"] ?? "", FILTER_VALIDATE_INT, [
    "options" => ["min_range" => 17, "max_range" => 100],
]);
if ($umur === false) {
    $error[] = "Umur harus bilangan bulat 17-100";
}

// Email
$email = filter_var($_POST["email"] ?? "", FILTER_VALIDATE_EMAIL);
if ($email === false) {
    $error[] = "Email tidak valid";
}

// URL
$url = filter_var($_POST["url"] ?? "", FILTER_VALIDATE_URL);

// Float
$harga = filter_var($_POST["harga"] ?? "", FILTER_VALIDATE_FLOAT);

// Boolean
$aktif = filter_var($_POST["aktif"] ?? false, FILTER_VALIDATE_BOOLEAN);

// IP
$ip = filter_var($_POST["ip"] ?? "", FILTER_VALIDATE_IP);

Sanitasi dengan filter_var() #

<?php
// Hapus karakter non-email
$email = filter_var($input, FILTER_SANITIZE_EMAIL);

// Hapus tag HTML
$teks = filter_var($input, FILTER_SANITIZE_SPECIAL_CHARS);

// Hapus karakter non-digit
$telepon = preg_replace("/\D/", "", $input);

// Trim spasi
$nama = trim($input);

// Hapus newline berlebih
$pesan = preg_replace("/\n{3,}/", "\n\n", $input);

Contoh Form Validasi Lengkap #

<?php
$error = [];
$data = [];

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Nama
    $nama = trim($_POST["nama"] ?? "");
    if ($nama === "") {
        $error["nama"] = "Nama wajib diisi";
    } elseif (mb_strlen($nama) < 3) {
        $error["nama"] = "Nama minimal 3 karakter";
    } else {
        $data["nama"] = htmlspecialchars($nama, ENT_QUOTES, "UTF-8");
    }

    // Email
    $email = filter_var($_POST["email"] ?? "", FILTER_VALIDATE_EMAIL);
    if ($email === false) {
        $error["email"] = "Email tidak valid";
    } else {
        $data["email"] = $email;
    }

    // Umur
    $umur = filter_var($_POST["umur"] ?? "", FILTER_VALIDATE_INT, [
        "options" => ["min_range" => 17, "max_range" => 100],
    ]);
    if ($umur === false) {
        $error["umur"] = "Umur harus 17-100";
    } else {
        $data["umur"] = $umur;
    }

    // Jika valid, proses
    if (empty($error)) {
        // Simpan ke database, kirim email, dll.
        echo "Registrasi berhasil!";
    }
}
?>

<form method="post">
    <div>
        <label>Nama:</label>
        <input type="text" name="nama" value="<?= htmlspecialchars($_POST['nama'] ?? '', ENT_QUOTES, 'UTF-8') ?>">
        <span class="error"><?= $error["nama"] ?? "" ?></span>
    </div>
    <div>
        <label>Email:</label>
        <input type="email" name="email" value="<?= htmlspecialchars($_POST['email'] ?? '', ENT_QUOTES, 'UTF-8') ?>">
        <span class="error"><?= $error["email"] ?? "" ?></span>
    </div>
    <div>
        <label>Umur:</label>
        <input type="number" name="umur" value="<?= htmlspecialchars($_POST['umur'] ?? '', ENT_QUOTES, 'UTF-8') ?>">
        <span class="error"><?= $error["umur"] ?? "" ?></span>
    </div>
    <button type="submit">Daftar</button>
</form>

Tips: Saat menampilkan kembali input ke form, selalu gunakan htmlspecialchars() — mencegah XSS dan menjaga karakter khusus.

CSRF Protection #

CSRF (Cross-Site Request Forgery) adalah serangan di mana penyerang membuat user yang sudah login mengirim request tanpa sadar.

Cara Kerja #

  1. User login ke example.com — browser menyimpan session cookie.
  2. User membuka situs penyerang evil.com yang berisi: 
    <form action="https://example.com/hapus-produk" method="post">
    <input type="hidden" name="id" value="1">
</form>
<script>document.forms[0].submit();</script>
  3. Browser mengirim request ke example.com dengan session cookie — server mengira itu dari user asli.
  4. Produk terhapus!

Solusi: CSRF Token #

1. Generate token saat session dimulai:

<?php
session_start();

if (empty($_SESSION["csrf_token"])) {
    $_SESSION["csrf_token"] = bin2hex(random_bytes(32));
}

$csrfToken = $_SESSION["csrf_token"];

2. Sertakan token di form:

<form method="post" action="proses.php">
    <input type="hidden" name="csrf_token" value="<?= htmlspecialchars($csrfToken) ?>">
    <input type="text" name="nama">
    <button type="submit">Simpan</button>
</form>

3. Verifikasi token saat memproses:

<?php
session_start();

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $token = $_POST["csrf_token"] ?? "";
    $sessionToken = $_SESSION["csrf_token"] ?? "";

    if (!hash_equals($sessionToken, $token)) {
        http_response_code(403);
        die("CSRF token tidak valid");
    }

    // Token valid — proses form
    // ...
}

Tips: Gunakan hash_equals() untuk membandingkan token — mencegah timing attack. Jangan gunakan == atau ===.

Contoh Praktis #

1. Form Login dengan Validasi #

<?php
session_start();

$error = "";
$sukses = false;

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $email = filter_var($_POST["email"] ?? "", FILTER_VALIDATE_EMAIL);
    $password = $_POST["password"] ?? "";

    if ($email === false) {
        $error = "Email tidak valid";
    } elseif (strlen($password) < 8) {
        $error = "Password minimal 8 karakter";
    } else {
        // Cek ke database (contoh dengan PDO)
        $pdo = new PDO("mysql:host=localhost;dbname=toko", "root", "");
        $stmt = $pdo->prepare("SELECT id, nama, password FROM users WHERE email = ?");
        $stmt->execute([$email]);
        $user = $stmt->fetch(PDO::FETCH_ASSOC);

        if ($user && password_verify($password, $user["password"])) {
            $_SESSION["user_id"] = $user["id"];
            $_SESSION["user_nama"] = $user["nama"];
            $sukses = true;
            header("Location: dashboard.php");
            exit;
        } else {
            $error = "Email atau password salah";
        }
    }
}
?>

<form method="post">
    <?php if ($error): ?>
        <div class="error"><?= htmlspecialchars($error) ?></div>
    <?php endif; ?>

    <input type="email" name="email" placeholder="Email" required>

    ["nama" => "Keyboard Mechanical", "kategori" => "elektronik"],

3. Upload File dengan Validasi #

<?php
if ($_SERVER["REQUEST_METHOD"] === "POST" && isset($_FILES["foto"])) {
    $file = $_FILES["foto"];

    // Cek error
    if ($file["error"] !== UPLOAD_ERR_OK) {
        $error = "Upload gagal: kode " . $file["error"];
    } elseif ($file["size"] > 5 * 1024 * 1024) {
        $error = "Ukuran maksimal 5MB";
    } else {
        $finfo = new finfo(FILEINFO_MIME_TYPE);
        $mime = $finfo->file($file["tmp_name"]);

        if (!in_array($mime, ["image/jpeg", "image/png", "image/webp"], true)) {
            $error = "Format harus JPG, PNG, atau WebP";
        } else {
            $ext = match ($mime) {
                "image/jpeg" => ".jpg",
                "image/png" => ".png",
                "image/webp" => ".webp",
            };
            $namaBaru = bin2hex(random_bytes(16)) . $ext;
            $tujuan = __DIR__ . "/uploads/" . $namaBaru;

            if (move_uploaded_file($file["tmp_name"], $tujuan)) {
                $sukses = "Upload berhasil: $namaBaru";
            } else {
                $error = "Gagal menyimpan file";
            }
        }
    }
}
?>

<form method="post" enctype="multipart/form-data">
    <input type="file" name="foto" accept="image/*" required>
    <button type="submit">Upload</button>
</form>

4. Form Kontak dengan CSRF #

<?php
session_start();

if (empty($_SESSION["csrf_token"])) {
    $_SESSION["csrf_token"] = bin2hex(random_bytes(32));
}

$sukses = "";
$error = [];

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // Verifikasi CSRF
    if (!hash_equals($_SESSION["csrf_token"], $_POST["csrf_token"] ?? "")) {
        $error["csrf"] = "Token tidak valid";
    }

    $nama = trim($_POST["nama"] ?? "");
    $email = filter_var($_POST["email"] ?? "", FILTER_VALIDATE_EMAIL);
    $pesan = trim($_POST["pesan"] ?? "");

    if ($nama === "") $error["nama"] = "Nama wajib diisi";
    if ($email === false) $error["email"] = "Email tidak valid";
    if (mb_strlen($pesan) < 10) $error["pesan"] = "Pesan minimal 10 karakter";

    if (empty($error)) {
        // Kirim email atau simpan ke database
        $sukses = "Terima kasih, pesan Anda telah dikirim!";
    }
}
?>

<form method="post">
    <input type="hidden" name="csrf_token" value="<?= htmlspecialchars($_SESSION["csrf_token"]) ?>">
    <input type="text" name="nama" placeholder="Nama" value="<?= htmlspecialchars($_POST['nama'] ?? '') ?>">
    <input type="email" name="email" placeholder="Email" value="<?= htmlspecialchars($_POST['email'] ?? '') ?>">
    <textarea name="pesan" placeholder="Pesan"><?= htmlspecialchars($_POST['pesan'] ?? '') ?></textarea>
    <button type="submit">Kirim</button>
</form>

Tips dan Best Practice #

  1. Jangan pernah percaya input user — validasi dan sanitasi semua data.

  2. Gunakan $_GET untuk data read-only, $_POST untuk data yang mengubah state.

  3. Hindari $_REQUEST — gunakan $_GET atau $_POST secara eksplisit.

  4. Selalu cek $_SERVER["REQUEST_METHOD"] sebelum memproses form POST.

  5. Validasi di server — validasi JavaScript hanya untuk UX, bukan keamanan.

  6. Gunakan filter_var() untuk validasi email, URL, integer, float.

  7. Selalu htmlspecialchars() saat output input user ke HTML.

  8. Jangan percaya $_FILES["type"] — gunakan finfo untuk cek MIME type.

  9. Generate nama file unik untuk upload — jangan gunakan nama asli.

  10. Implementasikan CSRF token untuk form yang mengubah data.

  11. Gunakan hash_equals() untuk membandingkan token CSRF — mencegah timing attack.

  12. Batasi ukuran upload di php.ini (upload_max_filesize, post_max_size).

  13. Nonaktifkan eksekusi PHP di folder upload.

  14. Gunakan HTTPS untuk mengirim data sensitif.

  15. Set display_errors = Off di produksi — jangan tampilkan error ke user.

Ringkasan #

Superglobal Kegunaan Kapan Digunakan
$_GET Query string Pencarian, filter, pagination
$_POST Body request Login, registrasi, create/update
$_REQUEST Gabungan GET/POST/COOKIE Hindari — gunakan eksplisit
$_SERVER Info server/request Method, URL, IP, header
$_FILES File upload Upload gambar/dokumen
$_SESSION Data session Login state, CSRF token
$_COOKIE Data cookie Preferensi, remember me

Poin penting:

  • $_GET terlihat di URL — jangan kirim data sensitif.
  • $_POST tidak terlihat — cocok untuk data sensitif.
  • Selalu validasi dan sanitasi input user.
  • Gunakan filter_var() untuk validasi standar.
  • Selalu htmlspecialchars() saat output ke HTML — mencegah XSS.
  • Jangan percaya $_FILES["type"] — gunakan finfo.
  • Generate nama file unik untuk upload.
  • Implementasikan CSRF token untuk form yang mengubah data.
  • Jangan gunakan $_SERVER["PHP_SELF"] tanpa htmlspecialchars() — rentan XSS.
  • Cek $_SERVER["REQUEST_METHOD"] sebelum memproses form.
